# Phase 44D Web Capability Privacy Policy

The web capability profiler is privacy-preserving by default.

Blocked:

- persistent device identifiers
- raw full user agent persistence
- exact screen resolution persistence
- detailed GPU adapter vendor/device persistence
- IP address capture
- network speed tests
- endpoint pings
- media file probing
- clipboard or filesystem access
- local/session storage persistence by default
- cross-site tracking
- live profile upload

The browser-safe module returns a local object only. Upload requires a later explicit phase with user/session consent and a private artifact policy.
