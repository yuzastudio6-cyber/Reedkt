# Activation Phase Roadmap

Phase 18 starts the post-M17 activation track. Milestones 0-17 built the dry-run/static production runtime foundation. Activation moves that foundation toward human-run staging setup and controlled real video testing, one gate at a time. Phase 32 produced a private color-corrected export for the single approved controlled real-video chain. Phase 33C verified the approved BiRefNet runtime on a generated synthetic image only. Phase 33D then processed exactly one representative frame from the approved Phase 32 private export and produced private BiRefNet mask/cutout artifacts. Phase 33E composed the first private single-frame text-behind-subject preview from those artifacts. Phase 34D completed one bounded Real-ESRGAN sample from the approved Phase 33D frame. Phase 34E completed the Real-ESRGAN broader-scope policy decision after that bounded sample; full-frame/full-video enhancement and slow motion remain blocked. Phase 35A recorded the non-mutating SAM2 model approval workflow. Phase 35B downloaded and loaded only the approved SAM2.1 tiny checkpoint/config into private staging GCS. Phase 35C verified SAM2 runtime on generated/synthetic frames only. Phase 35D completed the controlled short real-video SAM2 temporal mask test on one approved segment only. Phase 35E completed the controlled private segment text-behind-subject preview from those masks. Phase 35F completed the private SAM2 feature E2E beta-readiness gate for the approved controlled video chain only. Phase 36A completed the non-mutating audio AI approval workflow and recommended DeepFilterNet first. Phase 36B stores only the approved DeepFilterNet v0.5.6 CLI and DeepFilterNet3 ONNX artifacts in private staging GCS. Phase 36C verified the generated-audio DeepFilterNet runtime on synthetic audio only with private artifacts and no real media. Phase 36D completed the controlled real-video DeepFilterNet audio cleanup sample for the approved Phase 32 chain only. Phase 36E completed the private DeepFilterNet audio feature E2E gate on that same approved chain for internal testing only. Phase 36F closes the internal audio feature testing readiness gate for FFmpeg loudness plus DeepFilterNet only. Phase 36G removes RNNoise from active product flow and records Demucs as the vocal/music/stem separation candidate, but blocks htdemucs download/runtime because official pretrained-model license/provenance remains ambiguous. Phase 37A records PaddleOCR/PaddlePaddle approval for generated OCR safe-zone planning only. Phase 37B verified the exact PP-OCRv5 mobile det/rec/dictionary assets in private staging GCS. Phase 37C verified the generated OCR runtime on synthetic UI/text frames only for `phase37c-20260530T230413`. Phase 37D passes the metadata-only controlled real-video OCR/caption safe-zone planning gate and controlled execution run `phase37d-20260531T002046` for one private Phase 32 sample. Phase 37E completed Track B OCR safe-zone caption/render QA metadata integration for `phase37e-20260531T011259`. Phase 39A records Qwen3-VL/vLLM approval evidence for Track B VLM planning only. Phase 39B verified the exact Qwen3-VL 8B asset set in private staging GCS for `phase39b-20260531T025648`. Production, external beta, broad media, providers, RNNoise, Demucs runtime, caption/render runtime execution, VLM runtime execution before Phase 39C, controlled real-frame VLM before Phase 39D, and Revideo remain blocked. FILM/slow motion remains separately scoped and does not unlock VLM/OCR scope.

This roadmap is not launch approval. Production-ready, external beta, paid production, and broad real user media remain blocked until the later gates explicitly pass. Codex must not approve broad model use, run providers, deploy GPU, download unapproved model weights, add secrets, or process arbitrary real media.
