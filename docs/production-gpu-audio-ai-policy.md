# Production GPU Audio AI Policy

DeepFilterNet and Demucs are GPU/audio AI candidates for future voice cleanup and music/speech separation.

Milestone 11 declares package readiness and model-weight placeholders only. It does not denoise, separate stems, run listening QA, process user audio, or download model weights.

DeepFilterNet must protect voice naturalness. Demucs is not a default cleanup path and is only justified when music/speech overlap evidence supports separation in a future approved plan.
