# Activation Phase Roadmap

Phase 18 starts the post-M17 activation track. Milestones 0-17 built the dry-run/static production runtime foundation. Activation moves that foundation toward human-run staging setup and controlled real video testing, one gate at a time. Phase 32 produced a private color-corrected export for the single approved controlled real-video chain. Phase 33C verified the approved BiRefNet runtime on a generated synthetic image only. Phase 33D then processed exactly one representative frame from the approved Phase 32 private export and produced private BiRefNet mask/cutout artifacts. Phase 33E composed the first private single-frame text-behind-subject preview from those artifacts. Phase 34D completed one bounded Real-ESRGAN sample from the approved Phase 33D frame. Phase 34E completed the Real-ESRGAN broader-scope policy decision after that bounded sample; full-frame/full-video enhancement and slow motion remain blocked. Phase 35A recorded the non-mutating SAM2 model approval workflow. Phase 35B downloaded and loaded only the approved SAM2.1 tiny checkpoint/config into private staging GCS. Phase 35C verified SAM2 runtime on generated/synthetic frames only. Phase 35D completed the controlled short real-video SAM2 temporal mask test on one approved segment only. Phase 35E completed the controlled private segment text-behind-subject preview from those masks. Phase 35F completed the private SAM2 feature E2E beta-readiness gate for the approved controlled video chain only. Phase 38A recorded the Track A FILM slow-motion approval workflow. Phase 38B downloaded and loaded only the approved official FILM `film_net/Style/saved_model` artifact tree into private staging GCS. Phase 38C completed FILM runtime verification on generated frames only. Phase 38D completed one controlled selected real-video FILM slow-motion sample on a bounded Phase 32 segment only. Phase 40A records the non-mutating Track A pro color/image approval workflow for OpenColorIO, OpenImageIO, and Kornia. Phase 40B completed generated-fixture runtime verification for those tools only. Phase 40C completed one bounded Track A real-video sample from the approved Phase 32 private export using three downscaled frames only. Phase 40D completed the private Track A pro color/image feature E2E readiness gate and is ready only for internal pro color/image feature testing. Phase 45A completed libass caption burn-in validation on a bounded private preview sample from the approved Phase 32 export and Phase 28 ASS captions. Phase 45B completed Remotion render validation on a bounded private preview using the approved Phase 45A preview. Phase 45C completed OpenTimelineIO-compatible timeline validation for the controlled private render chain. Phase 45D completed FFmpeg/FFprobe final render/export hardening for one bounded private review export. Phase 45E completed full visual-video private E2E validation and is ready only for internal private visual-video testing. Final delivery, production, external beta, broad media, providers, Revideo, public delivery, arbitrary media, and Track B tools remain blocked.

This roadmap is not launch approval. Production-ready, external beta, paid production, and broad real user media remain blocked until the later gates explicitly pass. Codex must not approve broad model use, run providers, deploy GPU, download unapproved model weights, add secrets, or process arbitrary real media.
