## Fixture Rules

Every scenario must use synthetic IDs and synthetic metadata. Expected blockers are a pass condition when the blocked capability is outside the current milestone. A scenario fails if it stores secrets, signed URLs, private media, real money, raw PII, raw transcripts, provider payloads, or starts a runtime execution path.
