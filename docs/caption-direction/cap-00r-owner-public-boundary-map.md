## Neutral shared-contract gap

The committed base lacks the five shared surfaces CAP-01 needs:

1. `SkillCapabilityManifest` v2;
2. `SkillQualificationSnapshot`;
3. `SkillSupportRequest`;
4. `OrchestraSkillCall`;
5. `OrchestraSkillJobResult`.

They must be introduced once at a neutral shared path with strict,
byte-free, versioned, digest-bound, scope-bounded schemas. Existing manifest v1
must remain decodable when it is merged. CAP-11, Visual Intelligence, Track
All, Sound, Transition, and other specialist payloads stay independently owned
artifacts referenced from the support envelope.

## CAP-11 compatibility

One CAP-11 request/handoff may return multiple selected Living Frame scenes.
Cross-system occurrence identity therefore uses the complete tuple:

`receiverKind + outputId + sceneId + handoffId + request id/version/hash`.

The same request ref may recur for distinct scene scopes; exact duplicate tuples
fail closed. CAP-11 itself remains unchanged.
