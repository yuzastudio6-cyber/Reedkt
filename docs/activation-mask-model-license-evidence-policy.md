# Activation Mask Model License Evidence Policy

Model-weight evidence is separate from package, code, or runtime evidence.
A permissive repository license does not automatically approve all weights,
checkpoints, demos, third-party assets, or future variants.

## Evidence Records

Each evidence record must include:

- source name and URL
- source type
- license claim
- commercial-use claim
- redistribution claim
- attribution requirements
- review date
- confidence
- notes for conflicts or limitations

MIT and Apache-2.0 claims may be marked `likely_allowed`, but Phase 33A still
requires explicit staging review records and keeps production blocked.

Unknown, non-commercial, conflicting, or missing model-weight evidence blocks
approval.
