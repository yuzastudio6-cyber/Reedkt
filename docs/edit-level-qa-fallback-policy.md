# Edit Level QA Fallback Policy

QA fallback policy explains what the mock/local system should display when future gates are unavailable.

- Normal keeps a clean professional edit path and asks for clarification when source, marker, or copy-risk context is unclear.
- Premium shows degraded capability notices when visual, transcript, audio, Qwen, render, revision, or credit gates are unavailable.
- Ultra Premium degrades to Premium-safe QA policy until studio-level source, visual, audio, Qwen2.5-VL, render, revision, and credit systems exist.

Fallback policy is display and architecture metadata only. It does not execute fallback QA, retry providers, create worker jobs, reserve credits, or spend credits.
