# Phase 36K Demucs Source And License Evidence

Official/current evidence reviewed:
- `https://github.com/facebookresearch/demucs`
- `https://github.com/adefossez/demucs`
- `https://github.com/facebookresearch/demucs/blob/main/LICENSE`

The Demucs source/package license evidence is MIT, and PyPI lists Demucs 4.0.1 with MIT metadata. This is sufficient for source/package review notes, but it does not approve pretrained model weights.

The original Meta repository is archived/read-only. The maintainer fork exists, but its README says active feature work should not be expected. Any future Phase 36L runtime must pin exact source/package artifacts and pass dependency/security review.
