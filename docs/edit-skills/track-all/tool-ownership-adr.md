# ADR: Track All tool ownership

Decision: Track All has broad read visibility over the professional catalog and narrow, manifest-bound operation authority.

FFprobe owns technical truth. FFmpeg owns bounded deterministic media preparation and treatments. PySceneDetect proposes shot boundaries. OpenCV owns deterministic motion, homography, planar geometry, morphology, smoothing, and numeric QA. SAM 3.1 owns qualified promptable temporal masklets only. Kornia, OCR, and landmarks are conditional evidence producers. Visual Intelligence owns semantic grounding and inspection but cannot create/mutate masks, IDs, or Track Graphs. Remotion owns private composition previews. OpenTimelineIO owns interoperable timing handoff. Polars/DuckDB own tabular metrics.

Track All owns assignment authority, target reasoning, chunk/session plans, identity association, occlusion/re-entry, graph projection, treatment intent, QA aggregation, repair, and immutable result receipts.

Caption, Color, Motion Design, Sound, Transition, 3D, Living Frame, and Render retain their final-domain ownership. Track All emits model-neutral geometry and masks; it does not import peer private code. The head orchestra is outside this decision and is not implemented.
