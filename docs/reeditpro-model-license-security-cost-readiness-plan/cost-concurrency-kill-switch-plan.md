# Cost, Concurrency, And Kill Switch Plan

Required future cost evidence:

- per-provider and per-route budgets;
- per-user spend limits;
- concurrency and queue-depth limits;
- provider and route kill switches;
- approved credit estimate and reservation enforcement;
- refund/release policy for failed generation.

The production credit ledger remains blocked pending backend/database/billing gates. This plan does not run provider calls or billing operations.
