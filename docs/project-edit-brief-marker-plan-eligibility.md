# Project Edit Brief Marker Plan Eligibility

Markers are eligible for mock plan hints when they are confirmed, ready for plan, or fixture-marked as applied; have `passed` or `warning` QA; have usable structured intent; have valid time ranges; and have required metadata-only assets where needed.

Markers are skipped when QA is blocked, conflict, needs asset, or needs clarification; when intent is missing or blocked; when time ranges are invalid; when copy-risk exists; or when the marker is not confirmed.

Warning markers can be included as warning-tagged hints only. Missing assets, conflict, copy-risk, and unclear intent remain visible as skipped marker reasons. No real planner, automatic fix, planner application, render, provider, worker, credit, media, or Supabase action is started.
