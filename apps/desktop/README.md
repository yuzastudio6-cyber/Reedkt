# ReeditPro Desktop App Boundary

`apps/desktop` is reserved for a future desktop product path. It is not an active Mac or Windows runtime in Phase 44A.

## Owns Later

- desktop shell
- install capability wizard
- local worker bridge
- local cache
- local preview tools

## Must Not Own Yet

- active Mac/Windows runtime
- Tauri/Electron packages
- local AI execution
- installer scripts
- hardware scan execution

## Phase 44A Status

Desktop is future/planned only. Do not install Tauri, Electron, Electron Forge, installer tooling, hardware scan logic, local worker execution, or local AI runtime dependencies in this phase.
