## Media and QA Path

The confined FFmpeg runtime uses network mode `none`, read-only filesystem,
non-root execution, bounded temp/output storage, exact input byte counts, and
SHA-256 verification. It decodes only approved audio ranges, converts each
range to stereo 48 kHz signed 24-bit PCM, streams the exact expected bytes
through a FIFO, and losslessly encodes the continuous result as FLAC.

The first large six-hour run correctly failed closed because the metadata
FFprobe process consumed only a large FLAC header and closed stdin before the
host checksum verifier had streamed every byte. The repair makes the metadata
pass use `-count_frames` and requires positive read-frame evidence, forcing a
complete checksum-verified input read. A separate confined decoder then streams
the FLAC again and proves the exact decoded byte/sample count. The canonical QA
attempt independently repeats the full metadata and decoded-sample checks
against the create-only persisted artifact.
