# Desktop Capability Profiler

Phase 44E adds a Node/desktop-safe capability profile shape for future Track B route planning hints. It records coarse buckets only and does not execute routes, workers, media tools, providers, benchmarks, or local sidecars.

The default Phase 44E reports use generated/mock fixtures. Optional local collection is session-only, disabled unless explicitly confirmed, and must never persist or upload a live profile in this phase.
