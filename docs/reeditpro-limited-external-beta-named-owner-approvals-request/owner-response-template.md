# Owner Response Template

Each required owner must provide:

- owner name
- owner role
- owner slot
- approval decision
- approved or rejected scope
- approval timestamp
- accepted duty or explicit rejection reason
- explicit exclusions
- evidence reference

Accepted decisions are `approved_limited_external_beta_scope` or `rejected_limited_external_beta_scope`.

Silence, placeholder owner names, generic readiness text, unnamed approvals, and approval inferred from diagnostics are not valid approvals.
