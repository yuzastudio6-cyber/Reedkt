# Activation First Mask Test Model Scope

The first mask test is representative-frame/single-frame background removal.

## In Scope

- `ZhengPeng7/BiRefNet`
- one or more representative frames in a later controlled phase
- private mask/background-removal artifacts
- mask QA before any composition use

## Out Of Scope

- SAM2 video tracking
- text-behind-subject execution
- temporal mask propagation
- final public delivery
- broad real user media
- production or external beta

Text-behind-subject remains blocked until a later runtime verifies mask quality
and mask QA passes on controlled private media.
