# Provider Model Policy

Source policy preserved from `model-routing-policy.md`:

- GPT-Image-2 for stills, keyframes, graphics, cards, and frame design.
- Wan primary for animation.
- Hailuo fallback for animation.
- Veo 3.1 Lite is Premium-only final fallback/rescue and never the default route.
- Basic and Pro must never use Veo.

All provider routing remains planning data until the user approves the edit plan and credit estimate and until backend/provider execution gates are accepted.
