# Living Frame Active Private Internal Test

## Purpose

`living-frame-active-private-internal-test-v1` is the executable replacement
for using the historical character/rigging-heavy Living Frame aggregate as an
active completion signal.

It runs only the owner-approved non-character baseline and produces one
structured report across the exact twelve active cases. It never imports the
old Musashi, character-keypose, ToonCrafter/RIFE, Blender character-rig,
OpenToonz character-rig, or mechanical-rig aggregate cases.

## Exact run set

The runner executes ten unique child regressions:

- six source-contract regressions for baseline fallback routing, exact
  non-character source lineage, semantic SoundSync timing, professional-review
  policy, postrender visual-inspection policy, and evidence admission; and
- four actual private engineering media runtimes for all five modes, confirmed
  output frames, motion-v3/deep-multiplane behavior, and the selected-scene
  environmental-particle composition.

Shared child evidence may support several active cases, but every case keeps
its own ordered mapping and evidence digest.

## Honest evidence boundary

The report deliberately remains
`engineering_runtime_executed_professional_canonical_evidence_incomplete`.
Even when all ten child runs succeed, it records:

- no provider-backed Qwen postrender inspection;
- no separate canonical full-duration audio evidence;
- no Kimi-primary/Terra-fallback Head QA recommendation;
- no canonical private-review approval;
- no released advanced SAM2 temporal-mask evidence;
- no exact canonical map/route/data runtime fixture; and
- no canonical one-writer consumption of the feature contracts.

Consequently, no case may count toward active completion yet. Technical pixel,
motion, FFprobe, and runtime metrics are engineering evidence only and cannot
approve professional visual quality.

## Run discipline

The aggregate starts real Remotion, FFmpeg/FFprobe, PixiJS, and private
artifact test paths. Run it only during an explicit clean shared-runtime
window:

```text
npm run smoke:living-frame-active-private-internal-test
```

The runner is source-ready but has not been executed in the current milestone
because the canonical backend owns the shared media runtime. After execution,
the returned report must be visually inspected and then supplemented by the
canonical Qwen, audio, Head QA, repair, reconciliation, and private-review
chain before internal readiness can become true.
