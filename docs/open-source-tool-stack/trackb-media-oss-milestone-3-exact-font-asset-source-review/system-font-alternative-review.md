# System Font Alternative Review

Reviewed candidates:

- `fonts-noto-cjk`
- `fonts-noto-cjk-extra`

These are plausible safer Debian/Ubuntu package candidates because Noto CJK is distributed under the SIL Open Font License. This review does not approve installation or Dockerfile mutation, and it does not prove PaddleX/PaddleOCR can use a Noto substitute without hitting the PingFang fetch path.

Result: viable future strategy, not selected in this phase.
