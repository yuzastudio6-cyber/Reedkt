# Project Edit Brief Plan Priority Policy

The mock plan bridge uses this exact priority order:

1. Safety / do-not-copy / policy
2. Confirmed Edit Brief markers
3. Main Edit Chat instructions
4. Edit Preference / Preference DNA
5. Auto Professional suggestions
6. Default editing style

Safety and do-not-copy policy outrank every creative instruction. Confirmed Edit Brief markers outrank general Edit Preference/DNA for their time range unless QA blocks them. Conflict and copy-risk markers are skipped until user review.

This is a mock/local policy summary only. No real planner, edit plan, render, worker, provider, media, credit, or Supabase action runs.
