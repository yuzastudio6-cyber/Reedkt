# Living Frame Representative Media Source Candidates

## Purpose

`living-frame-representative-media-source-candidates-v1` identifies a bounded
private internal-test source set for the twelve active non-character cases. It
does not download, ingest, crop, transcribe, approve, or render any external
media.

The source smoke rereads the exact committed PNG byte lengths and SHA-256
digests. External media bytes are intentionally absent.

## Required admission steps

Before representative rendering, the canonical source/asset owners must:

1. review license, attribution, trademark, publicity, and person-use limits;
2. ingest exact immutable bytes into private storage;
3. select a semantically valid A-roll segment from transcript and source video;
4. select exact image crops without misleading historical or geographic use;
5. freeze exact data rows and citations through documentary fact safety;
6. bind every source to approved snapshot, selected scene, MasterTiming, work,
   asset manifest, confirmed frame, and renderer inputs; and
7. keep every source private and non-customer-facing until visual/audio/Head QA
   and canonical private review pass.

The candidate set contains only byte-free source reference IDs and digests. It
contains no external URL, path, credential, prompt, command, environment, or
media byte in an executable payload and creates no parallel source owner.
