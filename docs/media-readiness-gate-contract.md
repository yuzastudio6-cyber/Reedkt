# Media Readiness Gate Contract

These gates must block future planning, worker, render, provider, and tool execution unless they pass. Prompt 9 represents the gates but does not execute downstream work.

| Gate | Purpose | Checked by | Required records | Pass condition | Fail condition | Failure status | User-facing message style | Audit event | Future notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `AuthGate` | Require authenticated user. | API middleware | user session | User context exists. | Missing/invalid auth. | `blocked` | Ask user to sign in. | `media.auth_missing` | Existing auth middleware owns this. |
| `WorkspaceGate` | Scope media to workspace. | Media service | `workspaces`, `workspace_members` | Project belongs to workspace. | Workspace mismatch. | `blocked` | Say media is not accessible. | `media.workspace_blocked` | Must never leak cross-workspace media. |
| `ProjectAccessGate` | Require project membership. | Project service | `projects`, `workspace_members` | User is project workspace member. | Non-member or missing backend. | `backend_required`/`blocked` | Say project access cannot be verified. | `media.project_access_blocked` | Uses Prompt 3 access path. |
| `StorageObjectGate` | Verify canonical object reference. | Media/storage service | `storage_object_records` | Bucket/path exists and matches project scope. | Missing or noncanonical path. | `blocked` | Ask user to complete upload. | `media.storage_missing` | Signed URLs are not source of truth. |
| `SourceMediaExistsGate` | Ensure source media record exists. | Media service | `media_assets` | Media asset exists for project. | Missing asset. | `blocked` | Ask user to upload source media. | `media.source_missing` | No storage download is attempted. |
| `SourceMediaPrivateGate` | Preserve private media default. | Storage/media service | `storage_object_records` | Private bucket/path policy assumed. | Public URL/signed URL source truth. | `blocked` | Say media privacy needs repair. | `media.privacy_blocked` | Future RLS/storage tests must verify. |
| `MediaMetadataGate` | Require safe metadata. | Media service | `media_assets` | Content type and safe metadata present. | Missing/unsafe metadata. | `blocked` | Ask for media readiness retry. | `media.metadata_missing` | No secrets or signed URLs in JSONB. |
| `MediaProbeGate` | Require probe result before analysis/render. | Media service/future worker | future probe record | Probe complete and trusted. | Probe missing. | `backend_required` | Say probe worker is not enabled. | `media.probe_required` | Prompt 9 does not run probe. |
| `MediaDurationGate` | Require duration. | Media service | `media_assets` or probe record | Duration is present. | Duration missing. | `blocked` | Ask user to wait for readiness. | `media.duration_missing` | Needed for timing/planning. |
| `MediaResolutionGate` | Require dimensions. | Media service | `media_assets` or probe record | Width/height present. | Dimensions missing. | `blocked` | Ask user to wait for readiness. | `media.resolution_missing` | Needed for render frame planning. |
| `MediaFrameRateGate` | Require frame rate for video. | Media service | `media_assets` or probe record | Frame rate present. | Frame rate missing. | `blocked` | Ask user to wait for readiness. | `media.frame_rate_missing` | Needed for frame-accurate timing. |
| `MediaAudioStreamGate` | Verify audio stream when needed. | Media service/future worker | probe record | Audio stream known. | Audio stream unknown. | `backend_required` | Say audio probe is not enabled. | `media.audio_stream_required` | No audio analysis in Prompt 9. |
| `SourceSequenceGate` | Preserve uploaded order. | Media service | `uploaded_clips`, `source_sequence_items` | Source order records are present. | Missing or unconfirmed order. | `backend_required`/`blocked` | Ask user to confirm source order. | `media.source_sequence_blocked` | Must reset approval when changed. |
| `TranscriptReadinessGate` | Require transcript readiness. | Media service/future worker | future transcript records | Transcript ready when required. | Missing transcript. | `backend_required` | Say transcript worker is not enabled. | `media.transcript_required` | No AI transcription in Prompt 9. |
| `TranscriptTimingGate` | Require timed transcript anchors. | Timing service/future worker | future transcript segments | Timed anchors present. | Timing missing. | `backend_required` | Say transcript timing is pending. | `media.transcript_timing_required` | Needed for captions/cuts. |
| `VisualObservationReadinessGate` | Require visual observations when needed. | Future worker | future observation records | Observations complete. | Missing observation. | `backend_required` | Say visual analysis is not enabled. | `media.visual_observation_required` | No OCR/VLM/object/face detection in Prompt 9. |
| `AudioObservationReadinessGate` | Require audio observations when needed. | Future worker | future audio records | Observations complete. | Missing observation. | `backend_required` | Say audio analysis is not enabled. | `media.audio_observation_required` | No audio analysis in Prompt 9. |
| `TimingSeedGate` | Require timing seed facts. | Media/timing service | media metadata, future timing records | Duration/frame rate sufficient. | Missing timing facts. | `blocked` | Ask user to wait for readiness. | `timing.seed_blocked` | No timing persistence in Prompt 9. |
| `TimingValidationGate` | Require timing validation before approval/render. | Future timing QA | `master_timing_maps` and checks | Timing validation passes. | Missing/failing validation. | `backend_required` | Say timing validation is not enabled. | `timing.validation_required` | Future frame-accurate QA. |
| `WorkerRuntimeGate` | Ensure worker runtime exists. | Media/job service | worker runtime config | Runtime enabled and claimable. | Missing runtime. | `backend_required` | Say worker runtime is not enabled. | `worker.runtime_blocked` | Prompt 9 does not claim workers. |
| `JobExecutionBlockedGate` | Prevent job starts. | Job/media service | job records | Future approved job exists. | Prompt 9 request tries to start job. | `blocked` | Say job execution is disabled. | `jobs.execution_blocked` | Prompt 8 stays fail-closed. |
| `ProviderExecutionBlockedGate` | Prevent providers. | Provider/media service | provider attempts | Future approved route exists. | Provider call requested. | `blocked` | Say provider execution is disabled. | `provider.execution_blocked` | No providers in Prompt 9. |
| `RenderExecutionBlockedGate` | Prevent rendering. | Render/media service | render jobs | Future render path approved. | Render requested. | `blocked` | Say rendering is disabled. | `render.execution_blocked` | Prompt 10 handles render foundation. |
| `ToolExecutionBlockedGate` | Prevent tool execution. | Tool/media service | tool runtime checks | Future tool route approved. | Tool execution requested. | `blocked` | Say tool execution is disabled. | `tool.execution_blocked` | No tools in Prompt 9. |
