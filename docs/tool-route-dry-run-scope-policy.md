# Tool-Route Dry-Run Scope Policy

Allowed future scope is metadata only: approved plan snapshot route-intake validation, route candidate lookup, owner-study coverage validation, route compatibility classification, artifact/source-of-truth validation, no-op route state simulation, cost/capacity estimate shaping, and audit event shaping.

Blocked: real tool execution, worker execution, route execution, provider/model calls, media/audio/render/export/image generation/image editing, browser capture, map rendering, Supabase writes, GCS uploads, public artifacts, signed URLs, production, external beta, paid production, dependency mutation, and raw prompt execution.
