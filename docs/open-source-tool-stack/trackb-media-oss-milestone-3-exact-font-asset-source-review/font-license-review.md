# Font License Review

The reviewed PaddleX Python source is Apache-2.0, but that does not prove the standalone license for the external `PingFang-SC-Regular.ttf` file fetched from PaddleX font assets.

License facts not proven:

- Exact font license.
- Redistribution rights.
- Private staging rights.
- Repo commit rights.
- Cloud runtime image bundling rights.

Decision: keep the lane blocked pending font license review. Do not stage or fetch the asset.
