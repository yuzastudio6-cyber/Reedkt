# Phase 36J Private Artifact Policy

Phase 36J private artifacts may be uploaded only to:

`gs://reeditpro-staging-reeditpro-qa-artifacts/activation/phase36j/controlled-real-media-timing-stretch/<run-id>/`

Allowed private artifacts include JSON reports, bounded input audio, controlled stretched outputs, hashes, and metrics. Committed artifacts are limited to safe metadata and docs. Controlled video, raw audio payloads, stretched audio payloads, waveforms, spectrograms, transcripts, secrets, public URLs, signed URLs, and broad media metadata must not be committed.
