# External-Agent Boundary

The ready state applies only to a narrow external-agent controlled generated fixture runtime path.

Allowed future path:

- External agent may consume the accepted source evidence and route path.
- Future execution must stay scoped to generated fixture inputs unless a later packet explicitly approves another source class.
- Future execution must preserve the existing no-private-media, no-user-media, no-public-artifact, no-signed-url, no-final-export boundary.

This rollup does not authorize:

- Route execution in this rollup phase: `false`.
- Worker execution in this rollup phase: `false`.
- GStreamer execution in this rollup phase: `false`.
- MKVToolNix execution in this rollup phase: `false`.
- FFmpeg/FFprobe execution in this rollup phase: `false`.
- Docker execution in this rollup phase: `false`.
- Supabase mutation: `false`.
- SQL execution: `false`.
- Signed URL creation: `false`.
- Public artifact creation: `false`.
- Final render/export: `false`.
