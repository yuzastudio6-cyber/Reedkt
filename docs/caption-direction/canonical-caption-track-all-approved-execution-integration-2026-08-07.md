## Outcome

The canonical Caption execution owner now continues an exact approved scene
through the sequential authenticated-support chain required by advanced Track
All treatments:

1. canonical transcript reread;
2. postapproval PictureLock and finish-readiness reread;
3. Visual Intelligence final-frame occupancy request and evidence projection;
4. typed Track All request derived from the locked scene, confirmed output
   frame, near-final visual proxy, source-frame mapping, visual observations,
   and transcript lineage;
5. Track All owner projection and evidence reread;
6. Caption specialist continuation with the prior visual evidence preserved.

The one-at-a-time support coordinator does not mark a later owner request as
consumed before its predecessor has been promoted. The central Caption
execution service rereads both the current Track All evidence record and the
prior Visual Intelligence record. It refuses crossed call, request, scene,
output, or digest lineage.

## Test-fixture boundary

The Track All campaign fixture is structural source evidence only. It exists to
exercise closed request, projection, persistence, reread, and sequential resume
contracts. The fixture does not run SAM 3.1, OpenCV, Kornia, a GPU, or an
independent private visual review and is not admitted as private qualification
evidence.

The focused asynchronous owner harness separately verifies the three request
semantics:

- subject occlusion: mask required, anchor not required;
- object anchoring: anchor required, mask not required;
- environmental anchoring: anchor required, mask not required.

Real Track All qualification remains owned by the canonical Track All/SAM 3.1
path and still requires its admitted model/checkpoint/runtime, complete requested
interval, deterministic mask/anchor measurement, independent private visual
review, persistence, reread, and reconciliation evidence.

## Authority boundary

Caption does not receive Track All dispatch, provider, model, GPU, runtime,
timeline, asset mutation, cost, billing, final-QA approval, public delivery, or
production authority. The Track All record remains owner-produced and opaque;
Caption consumes only its exact typed projection. No central Orchestra was
implemented.
