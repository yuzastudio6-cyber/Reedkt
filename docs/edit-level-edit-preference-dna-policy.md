# Edit Level Edit Preference DNA Policy

Edit Preference / Preference DNA is reusable style intelligence. It should guide style without copying references shot for shot or overriding explicit user intent.

## Level Policy

| Level | Preference DNA use | QA expectation |
| --- | --- | --- |
| Normal | Safe style hints for pacing, caption tone, color restraint, and simple audio taste. | Confirm no obvious mismatch with user intent. |
| Premium | Strong style/DNA application across story structure, pacing, captions, cards, color, sound, and visual restraint. | Check Preference DNA match and marker conflicts. |
| Ultra Premium | Deep DNA application across story, visual identity, sound design, motion/card direction, and plan revision reasoning. | Stricter DNA QA and consistency review. |

## Source Of Truth

RP-EDITLEVEL-00 found Reference DNA surfaces but not a dedicated Edit Preference runtime source of truth in this checkout. RP-EDITLEVEL-01 should document that gap rather than creating duplicate placeholder systems.

## Boundary

This policy has no runtime implementation. Future resolver, persistence, UI, and QA wiring belong to later milestones.
