# Desktop Local Worker Future Plan

The local worker is a future concept for a desktop product path. It is not implemented in Phase 44A.

## Concept

A future desktop local worker could help with local preview/proxy/waveform tasks, local cache management, and bridge logic between the desktop shell and cloud-backed ReeditPro projects.

## Not Implemented Yet

Phase 44A does not add a local worker process, sidecar protocol, hardware scan, installer script, local AI runtime, model downloads, desktop framework, or compute routing implementation.

## Default Compute Policy

Local AI is not default. Heavy editing, model policy, private artifacts, readiness, provider gates, and Cloud Run orchestration remain server-owned. Any later local worker must prove privacy, consent, fallback, versioning, and support behavior before it can participate in approved compute routing.
