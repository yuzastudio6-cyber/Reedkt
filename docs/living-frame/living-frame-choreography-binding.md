# Living Frame choreography binding

Status: controlled source contract. It is not a timing plan, SoundSync plan,
renderer plan, approved snapshot, work graph, tool route, or runtime profile.

This binding connects the creative direction in one validated Living Frame
scene to an exact deterministic motion candidate without letting the motion
compiler reinterpret the story. It exists because technically valid keyframes
are not sufficient evidence that the intended attention journey, semantic
scale, stillness, or narration protection has been respected.

## What it proves

- Every semantic attention event has an explicit candidate mapping.
- Focus-depth, camera, motion-emphasis, and light-emphasis requests are backed
  by compatible deterministic tracks.
- A restore event has a candidate track that returns to its initial value,
  unless the scene explicitly transitions away.
- Local-contrast requests remain blocked until a canonical renderer primitive
  exists; they are not silently translated into blur.
- Literal geography and data-proportional visuals cannot be enlarged through
  a component scale track. Perspective and disclosed editorial scale require
  an explicit scale track.
- The existing one-primary-motion-group rule remains intact.
- Components with no motion tracks remain intentional still design states.
- Every sound request has exactly one semantic attention trigger.
- A motion-dependent component-linked sound trigger includes motion from that
  exact component; it cannot be attached to an unrelated moving object.
- Environmental presence may remain tied to an attention event without
  forcing a static environment to move merely to justify ambience.
- Sound triggers preserve their attention event, event type, and motion-track
  lineage while exact frames remain unset.
- Sound requests retain strict narration protection and stay semantic until
  the existing SoundSync authority assigns meaning-bound cue frames, ducking,
  gain, panning, attack/release, and mix.

## What it cannot prove

The binding cannot select a scene, change MasterTiming, place sound cues,
approve a plan, reserve credits, mutate a renderer plan, create assets, build a
work graph, select tools or providers, call Remotion, or approve private
review. Those authorities remain literal `false`.

Musashi, helicopter, and Strait of Hormuz remain fixture subjects only. The
contract routes by scene semantics, component relationships, attention
methods, scale truth, and motion properties. `subjectSpecificRouting` is always
`false`.

## Remaining canonical integration

The server must re-read the current Living Frame component and motion bundle,
revalidate their digests against the same MasterTimingPlan and output frame,
project each sound request through the existing SoundSync planner using its
exact semantic attention trigger, project layers through the existing
RendererCompositionPlan, and freeze the resulting references in the one
immutable approved snapshot before any existing work graph may execute.

The current canonical Living Frame timing compiler must not treat request order
as a semantic trigger. Even spacing across the visual range is not sufficient
evidence that an SFX or ambience cue is tied to a visual action. Exact
attention-event timing, mix envelopes, voice ducking, spatial placement,
asset provenance, audio QA, and private review remain canonical-owner gates.
