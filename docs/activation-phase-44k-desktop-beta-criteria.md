# Phase 44K Readiness Criteria

Phase 44K passes only when all 20 required criteria pass:

- Capability manifests exist and passed.
- Route manifest exists and passed.
- Web capability profiler exists and passed.
- Desktop capability profiler exists and passed.
- Desktop benchmark runner exists and passed.
- Cost estimator exists and passed.
- Local worker sidecar foundation exists and passed.
- Hybrid compute E2E simulation exists and passed.
- VLM routes remain excluded.
- Demucs remains blocked pending provenance/legal review.
- Route execution remains disabled.
- Worker and sidecar execution remain disabled.
- Public artifacts remain blocked.
- Broad and arbitrary media remain blocked.
- Provider calls remain blocked.
- Raw chat execution remains blocked.
- Frontend secret access remains blocked.
- Track A remains untouched.
- Docs, runbooks, rollback, and support policies exist.
- Smoke and report scripts exist and pass.

If any criterion fails, desktop/hybrid compute beta status remains `blocked`.
