# REEDITPRO_LIMITED_EXTERNAL_BETA_RUNTIME_OWNER_APPROVAL_PLAN

Create a metadata-only owner approval plan for limited external beta runtime activation.

Do not enable external beta, production, live user traffic, worker dispatch, provider calls, media processing, render/export, storage writes, signed URLs, SQL, migrations, billing or credit mutations, or public delivery in the approval plan.

The plan must name or require release, incident, support, privacy/storage, billing/credit, and worker/runtime owners and define the exact later activation evidence required before any limited external beta execution.
