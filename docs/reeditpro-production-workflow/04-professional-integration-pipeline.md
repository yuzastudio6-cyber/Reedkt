# Professional Integration Pipeline

An Edit Cue is not a raw render command. Every cue must become a professional treatment plan before render.

The user gives direction, but the AI determines professional execution. Professional Integration turns user direction, clean assembly timing, source understanding, frame layout, captions, QA constraints, and credit-approved plan behavior into polished edit decisions.

## Professional Integration Decisions

Professional Integration should decide:

- best trim
- best crop
- placement
- safe zones
- caption avoidance
- face avoidance
- subject avoidance
- audio behavior
- color matching
- stabilization
- transition style
- overlay design
- card/framing style
- rounded corners
- shadow
- border
- motion entrance/exit
- privacy blur
- readability
- mobile-safe scale
- pacing
- hold duration
- exit timing

## Examples

### Example 1: Screenshot Cue

User says:

```text
Put this screenshot at 00:22.
```

AI treatment:

Use it as a floating proof card on the right side, add rounded corners, soft shadow, readable scale, blur private information, avoid captions and face, animate in smoothly, and hold long enough to read.

### Example 2: Kitchen B-roll Cue

User says:

```text
Use this kitchen clip as B-roll.
```

AI treatment:

Select the strongest subclip, crop to platform format, mute B-roll audio, preserve main voice, stabilize if needed, color match, cut on natural speech rhythm, and return to speaker before the next key idea.

### Example 3: Logo Cue

User says:

```text
Add my logo.
```

AI treatment:

Use logo as a brand asset, place with safe margins, avoid cheap watermark feel unless requested, use subtle intro/outro placement, and avoid covering captions or faces.

## No Raw Pasted Assets

The system must avoid:

- raw sharp-edge overlays unless intentionally requested
- bad crop
- unreadable text
- random placement
- overlays covering faces
- overlays covering captions
- unstyled screenshots
- awkward pop-in/pop-out
- B-roll audio clashing with main voice
- hard audio cuts
- low-resolution assets scaled too large
- off-brand graphic treatment

## QA Expectations

Professional Integration outputs should be checked by QA before preview is ready. QA should verify cue compliance, caption safety, face and subject safety, readability, audio behavior, color matching, pacing, approved-plan compliance, and credit/approval gates.
