# Phase 44G Route/Cost/Capability Handoff

The sidecar foundation consumes Track B capability manifests, route manifests, web/desktop profiler metadata, desktop benchmark metadata, and Phase 44H cost estimator metadata.

It cannot choose tools by itself, override route manifests, override capability manifests, override cost guardrails, approve VLM, approve Demucs, approve broad media, approve public output, or execute routes.

Future execution must require approved plan snapshots, artifact scopes, private prefixes, route manifest version checks, cost policy checks, and fail-closed audit reporting.
