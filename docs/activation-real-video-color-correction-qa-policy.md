# Phase 32 Color Correction QA Policy

Phase 32 QA emits:

- `color_exposure`
- `color_skin_tone`
- `color_export_space`
- `color_shot_match`
- `export_codec_format`
- `export_duration_sync`
- `audio_sync`
- `final_delivery`

`color_skin_tone` is warning-only because no face or skin model runs. `color_shot_match` is warning/not-applicable because this phase uses one controlled clip.
