# Captions Specialist Decision Ledger

Precedence is: safety/legal requirements, `AGENTS.md`, the current user Goal,
latest explicit user corrections, this CAP-00R amendment, committed public
contracts, historical CAP-00 documents, then examples.

## Binding decisions

| ID | Decision | Consequence |
| --- | --- | --- |
| CS-001 | `captions` is the top-level specialist. | Future HQ assigns bounded jobs to `captions`; `caption_design` is not the callable specialist. |
| CS-002 | `caption_design` is the specialist's internal composite professional skill. | Scene-aware mini-skill assembly stays internal; `caption_direction` is an alias only. |
| CS-003 | `no_captions` is an explicit, mutually exclusive restraint. | Absence of caption selection is not silently treated as restraint. |
| CS-004 | Skills are implemented and qualified before the production Orchestra. | Build a standalone neutral-contract harness; do not build the HQ loop or global scheduler. |
| CS-005 | Jobs are bounded to video, scene, or boundary scopes. | Reject caller scope expansion, direct peer execution, cycles, and unsupported work. |
| CS-006 | One immutable canonical transcript drives every projection. | Creative, accessible, translated, ASS, SRT, WebVTT, and Remotion outputs retain source-word and transformation lineage. |
| CS-007 | Caption work is early-planned, mid-edit reserved, late-resolved, and late-rendered. | Exact choreography requires picture lock and current final-frame evidence. |
| CS-008 | StoryTiming is the sole final frame authority. | Captions submits requirements and consumes resolved events; it never owns a parallel clock. |
| CS-009 | Visual Intelligence owns visual analysis and postrender visual evidence. | Captions uses support requests and typed results; no direct Qwen Caption provider path. |
| CS-010 | Track All owns tracking, masks, anchors, occlusion, and temporal support. | New Caption work reaches SAM 3.1 only through Track All-compatible evidence; no direct SAM dispatch/import. |
| CS-011 | Creative typography may be beside, behind, in front of, attached to, or intentionally occluded by subjects/objects. | Track-specific depth is allowed only with evidence, QA, and a complete accessible projection. |
| CS-012 | A video may use multiple caption modes and simultaneous tracks. | Use a multi-track scene graph, not one global style stream. |
| CS-013 | Synthetic or interpolated word timing cannot drive final word-locked motion. | Phrase fallback or review is required without qualified provenance. |
| CS-014 | Caption-to-Visual, Living Frame, Transition, B-roll, camera, and Sound are separate owners. | Captions creates typed intent/handoff artifacts and never duplicates receiver execution. |
| CS-015 | Frozen CAP-11 remains unchanged. | Put its byte-free request/response payload and digest lineage inside future support-request/result envelopes. |
| CS-016 | Remotion owns creative/final composition, libass owns stable caption rendering, and FFmpeg owns packaging/probe operations. | Renderers execute typed approved specs; models never author executable code. |
| CS-017 | Direct visual inspection is part of QA for generated media. | Technical checks alone cannot promote professional appearance or complete visual QA. |
| CS-018 | The current Goal ends at `caption_specialist_private_internal_qualified`. | Public SaaS production is not required, but the Caption-owned surface and backend handoff must be complete and honest. |
| CS-019 | Self-review and automatic continuation replace routine owner pauses. | Check, repair, document, checkpoint, push, and continue after each milestone. |
| CS-020 | Illustrated-character animation and mechanical rigging are paused. | Those Living Frame research routes are non-admissible; non-character coordination remains available. |

## Examples, not defaults

Hero words, editorial serif/brush accents, persistent lists, text behind a
subject, spatial sentences, and Caption-to-map/Living-Frame transformations are
capabilities and fixtures. They are never random defaults or permission to copy
a creator's protected design.

## Owner decisions that remain external

- neutral shared-contract one-writer location and published base;
- approved transcript authority and alignment/diarization runtime releases;
- licensed fonts, FontTools/OTS/shaping images, and custom-font policy;
- canonical Track All support DTO if not already published;
- Sound support DTO and camera/reframe receiver identity;
- qualified provider lifecycle for Visual Intelligence postrender review;
- deployed persistence, billing, public delivery, and production release.

None permits a Caption-owned duplicate. Each is carried as a scoped gate while
unaffected implementation continues.
