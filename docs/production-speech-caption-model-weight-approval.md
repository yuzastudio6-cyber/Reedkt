# Production Speech Caption Model Weight Approval

Production transcription requires an approved faster-whisper model-weight manifest. The manifest must track model name, version, source, expected path, license, commercial-use permission, redistribution status, attribution, checksum if available, review status, and risk notes.

Unknown, non-commercial, missing, or unreviewed weights block paid production. Dry-run may continue with warnings. Local-dev may skip or warn, but never downloads models automatically.

Model-weight license approval is separate from faster-whisper, CTranslate2, Python, or container package approval.
