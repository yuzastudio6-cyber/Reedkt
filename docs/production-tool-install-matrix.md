# Production Tool Install Matrix

## Purpose

This matrix records planned production tool ownership and readiness status. It is not an install manifest. Milestone 0 does not install packages, download model weights, execute tools, process media, deploy containers, or approve licenses.

Milestone 2 adds the server-only production metadata registry under `server/tool-registry`. That registry is the implementation source for production tool profiles, worker ownership, runtime policy, QA gate mapping, fallback chains, and license/model-weight review status. This matrix remains documentation and does not install or execute any tool.

Install status values:

- `not_installed_by_m0`: planned but not installed by this milestone.
- `runtime_boundary_only`: documented as an integration boundary, not installed here.
- `evaluation_only`: future optional evaluation, not core.

Milestone 2 production registry coverage now includes these server-only `ProductionToolId` profiles:

- Core media/timeline/render: `ffmpeg`, `ffprobe`, `pyav`, `opentimelineio`, `hyperframe`, `remotion`, `libass`, `sharp`, `duckdb`, `polars`.
- Speech, transcript, OCR, scene, and visual analysis: `faster_whisper`, `whisper_cpp`, `paddleocr`, `pyscenedetect`, `opencv`, `mediapipe`, `kornia`.
- Background removal, masks, color, image, and finishing: `birefnet`, `sam2`, `transparent_background`, `rembg`, `opencolorio`, `openimageio`.
- Audio cleanup, audio analysis, music stretch, and source separation: `deepfilternet`, `rnnoise`, `demucs`, `librosa`, `audioflux`, `signalsmith_stretch`, `soundtouch`, `rubber_band`, `essentia`.
- Enhancement, interpolation, motion graphics, browser capture, maps, charts, and future visual layers: `real_esrgan`, `film`, `pixijs`, `three_js`, `babylon_js`, `lottie`, `playwright`, `maplibre`, `turf`, `d3`, `echarts`, `vega_lite`, `deck_gl`, `cesium_js`, `konva`, `vapoursynth`.
- Evaluation only: `revideo`.

## Revideo Policy

Revideo is not core, not launch-required, and not installed by this milestone. It may be evaluated later only if a concrete, documented Remotion/Hyperframe gap cannot be solved inside the locked core stack.
