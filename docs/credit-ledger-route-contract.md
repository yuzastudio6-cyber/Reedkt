# Credit Ledger Route Contract

Prompt 6 route contracts are backend-required unless explicitly read-only. Mutations validate input and idempotency, then fail closed with `BACKEND_REQUIRED` until a future transactional runtime exists.

| Route ID | Method / Path | Purpose | Caller | Auth | Tables touched | Service role | Idempotency | Status | Forbidden side effects |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `credits.wallet.get` | `GET /v1/workspaces/:workspaceId/credit-wallet` | Read sanitized workspace ledger summary. | Frontend/backend | Required, workspace member | `workspace_members`, `credit_ledger_entries` | Required for read | No | backend_required/read-only | No wallet mutation, grants, billing, Stripe, or legacy wallet table targeting. |
| `credits.estimate.create` | `POST /v1/projects/:projectId/credit-estimates` | Validate estimate creation request and return backend-required mutation boundary. | Frontend/backend | Required, project access | `projects`, `workspace_members`, future `credit_estimates`, `credit_estimate_items` | Required for future write | Yes | backend_required | No estimate row insertion, approval, reservation, job, provider, render, tool, Stripe, or storage execution. |
| `credits.estimate.get` | `GET /v1/credit-estimates/:creditEstimateId` | Read scoped estimate summary. | Frontend/backend | Required, project access | `credit_estimates`, `credit_estimate_items`, `projects`, `workspace_members` | Required for read | No | backend_required/read-only | No approval, reservation, or spend. |
| `credits.estimate.approve` | `POST /v1/credit-estimates/:creditEstimateId/approve` | Validate approval gate against canonical approval/snapshot references. | Frontend/backend | Required, project access | `credit_estimates`, `approval_records`, `approved_plan_snapshots`, `credit_reservations` | Required for future write | Yes | backend_required | No legacy credit approval write, no snapshot mutation, no reservation/spend. |
| `credits.gate.check` | `POST /v1/credits/gate/check` | Read-only gate check before expensive work. | Frontend/backend | Required, project access | `credit_estimates`, `approved_plan_snapshots`, `credit_reservations`, `credit_ledger_entries` | Required for read | No | backend_required/read-only | No downstream execution. |
| `credits.reservation.create` | `POST /v1/credit-estimates/:creditEstimateId/reservations` | Validate reservation creation request. | Frontend/backend | Required, project access | `credit_estimates`, `approved_plan_snapshots`, future `credit_reservations` | Required for future write | Yes | backend_required | No reservation row insertion or ledger mutation in Prompt 6. |
| `credits.reservation.get` | `GET /v1/credit-reservations/:creditReservationId` | Read scoped reservation summary. | Frontend/backend | Required, project access | `credit_reservations`, `projects`, `workspace_members` | Required for read | No | backend_required/read-only | No release, spend, refund, or status update. |
| `credits.reservation.release` | `POST /v1/credit-reservations/:creditReservationId/release` | Validate release readiness. | Backend/frontend after cancellation | Required, project access | `credit_reservations`, `credit_ledger_entries` | Required for future write | Yes | backend_required | No ledger insertion or reservation update. |
| `credits.reservation.spend` | `POST /v1/credit-reservations/:creditReservationId/spend` | Validate spend readiness. | Future backend execution only | Required, backend/project access | `credit_reservations`, `credit_ledger_entries` | Required for future write | Yes | backend_required | No job/provider/render/tool execution and no ledger insertion. |
| `credits.reservation.refund` | `POST /v1/credit-reservations/:creditReservationId/refund` | Validate refund readiness. | Future backend execution/support only | Required, backend/project access | `credit_reservations`, `credit_ledger_entries`, future `refund_records` | Required for future write | Yes | backend_required | No refund record or payment processor action. |
| `credits.ledger.listForProject` | `GET /v1/projects/:projectId/credit-ledger` | List sanitized project ledger entries. | Frontend/backend | Required, project access | `credit_ledger_entries`, `projects`, `workspace_members` | Required for read | No | backend_required/read-only | No ledger mutation. |
| `credits.blockers` | `POST /v1/credits/blockers` | Return current credit blockers for UI/debug. | Frontend/backend | Required, project access | Same as gate check | Required for read | No | backend_required/read-only | No mutation or execution. |
| `credits.readiness.check` | `POST /v1/credits/readiness` | Check credit runtime readiness. | Frontend/backend | Required, project access | Same as gate check | Required for read | No | backend_required/read-only | No mutation or execution. |

Compatibility route:

- `GET /v1/workspaces/:workspaceId/credit-balance` maps to the same sanitized ledger summary as `credits.wallet.get` for older callers.
- `POST /v1/credit-estimates/:creditEstimateId/reserve` maps to `credits.reservation.create` and remains backend-required/fail-closed.
