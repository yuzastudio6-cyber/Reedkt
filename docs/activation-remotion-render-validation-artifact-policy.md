# Phase 45B Remotion Render Validation Artifact Policy

Private preview artifacts are stored under `gs://reeditpro-staging-reeditpro-previews/activation-render-hardening/phase45b/`.

Plan snapshots, source validation, render metadata, FFprobe validation, QA, and Phase 45B reports are stored under `gs://reeditpro-staging-reeditpro-qa-artifacts/activation-render-hardening/phase45b/`.

Rendered previews, private JSON reports, logs, credentials, signed URLs, public URLs, and large binary outputs must not be committed to git.
