# Integration Boundary Map

Status: `docs_only`.

Every boundary uses approved manifests, structured metadata, and private artifact references. Raw chat, screenshots, signed URLs, provider secrets, public artifacts, and runtime side effects are not valid source-of-truth handoffs.

| Boundary | Upstream owner | Downstream owner | Allowed handoff artifacts | Blocked handoff artifacts | Required contract | Evidence required |
| --- | --- | --- | --- | --- | --- | --- |
| AI Tools to Track A | AI Tools / Creative Graphics | Track A Render / Export | Render-ready graphic asset manifests, Remotion composition briefs, SVG/Lottie/card metadata, timing and safe-zone requirements | Final export claims, raw runtime commands, public assets, signed URLs as source of truth | Approved plan snapshot plus render-ready graphics manifest | Static manifest validation and Track A acceptance |
| AI Tools to Track B | AI Tools / Creative Graphics | Track B Media Processing | Processing request manifest, source artifact references, desired derivative specs | Direct Sharp/libvips ownership claim, media blobs in docs, raw processing commands | Track B processing request contract | Track B capability/readiness evidence |
| AI Tools to Provider Gateway | AI Tools / Creative Graphics | Provider Gateway | Provider-neutral creative brief, prompt intent, safety constraints, approved model-route request | Provider API keys, direct provider call, raw prompt execution, model fallback changes | Provider gateway request envelope | Provider gateway readiness and secret-boundary evidence |
| AI Tools to Worker Runtime | AI Tools / Creative Graphics | Worker Runtime | Candidate job plan, approved snapshot references, tool capability requirements | Worker command execution, lease/claim mutation, raw chat instructions | Worker execution envelope and approved plan snapshot | Worker readiness and idempotency evidence |
| AI Tools to Supabase | AI Tools / Creative Graphics | Supabase/RLS/Storage/Database | Milestone/status metadata, schema needs, private `gs://` references, future table requirements | SQL, service-role code, DB URLs, row payloads, signed URLs | Supabase update classification and schema planning contract | Supabase owner confirmation |
| Map stack to AI Tools | Map / Geospatial | AI Tools / Creative Graphics | Map/location evidence manifests, GeoJSON, style/camera/timing metadata, rendered local QA references | MapLibre/Turf/deck.gl/CesiumJS ownership transfer, live tile URLs, geocoding/routing secrets | Map/geospatial artifact manifest | Map owner readiness evidence |
| Map stack to Track A | Map / Geospatial | Track A Render / Export | Map render/capture manifests and private artifacts | Public map tiles, live map provider keys, final export claim | Render handoff manifest | Network guard and artifact privacy evidence |
| Supabase to runtime domains | Supabase/RLS/Storage/Database | All runtime workstreams | Schema/RLS/storage contracts, table/readiness status, milestone sync policy | Service-role secrets, raw DB URLs, unreviewed SQL, unapproved migrations | Supabase owner approved schema/RLS contract | Local/staging validation or explicit blocked status |
| Provider Gateway to Worker Runtime | Provider Gateway | Worker Runtime | Provider request envelope, secret reference names, output readiness metadata | Direct provider call from worker outside gateway, provider key in job payload | Provider execution contract | Provider gateway and worker readiness evidence |
| Credits to Jobs | Billing / Credits | Worker Runtime / Jobs | Credit reservation/approval references and execution gates | Direct credit mutation by worker, Stripe payloads, unapproved spend | Credit gate contract | Credit ledger readiness evidence |
| Observability to all runtime domains | Observability / Audit / Cost | All runtime workstreams | Audit event schema, cost signals, request IDs, abuse-control metadata | Secrets, raw media, public artifacts, bypass of source manifests | Audit/cost event contract | Observability readiness evidence |
