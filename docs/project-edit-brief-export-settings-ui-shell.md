# Project Edit Brief Export Settings UI Shell

Export settings are `ProjectEditSession`-owned metadata accessible from the Edit Brief shell.

## Editable Mock Summary

The shell displays and can now update platform target, aspect ratio, resolution, frame rate, format, codec, audio codec, caption safe area, delivery preset, and summary copy as mock/local session-level metadata.

## Boundary

The Brief shell can save Export Settings metadata through existing mock route/client methods, but no render/export/progress job, provider/model call, worker, credit reservation, Supabase command, migration, upload, file-byte read, media processing, or external URL fetch starts from this panel.
