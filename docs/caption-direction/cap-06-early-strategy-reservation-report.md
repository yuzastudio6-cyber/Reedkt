## Planning behavior

The deterministic fixture proves all four classes in one bounded plan. Caption
selects only exact Visual Intelligence safe-region candidates, retains ranked
fallback regions, and blocks with a typed Visual Intelligence support need when
no safe region exists. It never invents a region or final placement.

Blocking metadata is approximate, visibly non-final, and non-renderable.
Estimate input covers transcription, alignment, diarization, visual evidence,
tracking/masks, output/language count, spatial scenes, hero typography,
cross-system handoffs, sound, render complexity, visual QA, and revision
allowance. It calculates no price, reserves no credits, and does not replace
the canonical estimate owner.

The approval envelope records requested limits and permissions while retaining
both canonical plan and estimate approval gates. `no_captions` requires an
exact owner-approved restraint reference and produces no opportunities,
reservations, estimate factors, hidden work, or caption execution.
