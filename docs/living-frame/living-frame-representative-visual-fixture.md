# Living Frame Representative Visual Fixture

## Purpose

`living-frame-representative-visual-fixture-v1` separates two kinds of
evidence that must never be confused:

- an engineering geometry probe can prove exact timing, layer order, literal
  scale, codec output, and deterministic motion; but
- professional visual acceptance requires a representative scene built from
  real or source-verified media and inspected as an actual edit.

The current five-mode private renderer uses colored shapes deliberately. It is
useful regression evidence, but it is not a product-quality visual target.

The companion
`living-frame-representative-direction-acceptance-v1` also requires each case
to use its own semantic action, five-phase relative timing, visual treatment,
depth strategy, motion budget, camera character, stillness policy, semantic
scale guard, and restrained sound palette. This prevents a green geometry or
runtime check from being mistaken for creative direction.

## Exact active coverage

The manifest defines one representative-media requirement for each of the
twelve owner-approved active cases. It covers real-source A-roll, unanimated
static illustration, non-character still motion, archive and document
composition, diagrams, hybrid expansion and return, maps/routes/literal data,
attention and Semantic Scale, camera/depth/occlusion/masks, environmental or
editorial motion, Caption/SoundSync coordination, and exact final Remotion
review and repair.

Every case binds:

- required canonical asset roles;
- the exact permitted motion policy;
- immutable source provenance and reread;
- confirmed output frame and MasterTiming;
- work and asset-manifest lineage;
- the ordered 13-check professional review;
- complete playback and complete-time Qwen visual evidence;
- separately verified audio evidence;
- Kimi-primary/Terra-fallback recommendation;
- canonical private review; and
- N+1 artifact repair followed by complete reinspection.

## Fail-closed rules

The manifest explicitly rejects professional acceptance based on:

- colored rectangles or synthetic geometry;
- placeholders;
- technical metrics without visual inspection;
- caller assertions;
- generated-video fallback;
- reuse of a failed artifact after repair;
- animated illustrated/living subjects;
- character keyposes or interpolation;
- living-subject rigs; or
- mechanical rig inference.

Static illustrations remain allowed only without illustrated-subject
animation. Simple rigid support transforms remain distinct from the paused
mechanical-rig system and must already be approved rather than inferred.

## Authority boundary

This is a byte-free source-only plan. It does not create assets, register an
operation, dispatch work, call Qwen, approve QA, perform private review, charge
a customer, or grant public/production authority. Canonical one-writer
consumption and actual representative-media execution remain pending.
