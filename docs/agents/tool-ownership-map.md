# Tool Ownership Map

Phase 52A records the canonical cross-track ownership map.

This chat owns web search/capture, map/geospatial planning, shared agent architecture, and system integration/readiness. This includes SearXNG, Brave optional fallback policy, controlled Playwright search/map capture usage, Mozilla Readability, source/capture/extraction manifests, MapLibre, Turf, deck.gl, CesiumJS, open map data policy, and future-scoped private tile/geocoder/router candidates.

AI Tools chat owns creative graphics and motion design tools: Remotion graphics, D3, Three.js, PixiJS, Anime.js, Lottie-web, SVG.js, ECharts, Vega/Vega-Lite, Viz.js, Satori, resvg, title cards, lower thirds, infographics, charts, diagrams, animated callouts, and render-ready graphic assets.

Track B owns audio/OCR/data/VLM/compute-routing tools: PaddleOCR, PaddlePaddle, OpenCV, PyAV, PySceneDetect, Sharp/libvips general capability, DuckDB, Polars, DeepFilterNet, Signalsmith Stretch, Demucs, Qwen3-VL, vLLM, profilers, sidecar planning, cost estimator, and tool route manifest integration.

Track A owns visual-video core evidence and runtime paths: FFmpeg, FFprobe, libass, Remotion render validation path, OpenTimelineIO, OpenColorIO, OpenImageIO, Kornia, BiRefNet, SAM2, Real-ESRGAN scoped path, FILM, and full visual-video private E2E.

Rules:

- No chat claims another chat’s tools without an explicit integration phase.
- Shared consumers consume capabilities through manifests.
- A consumer does not own the tool.
- Workers execute approved plan snapshots only.
