# Phase 45B Remotion Render Validation Policy

Only the approved Phase 32 private export and Phase 45A private burn-in preview/report may be used.

The validation worker executes an approved plan snapshot, not raw chat. It creates a bounded private preview sample only and never writes a final export.

Allowed tools are Remotion and FFprobe in the dedicated Phase 45B runtime image. Providers, Revideo, Track B tools, public URLs, production, external beta, paid production, broad real media, arbitrary media, and final delivery are blocked.
