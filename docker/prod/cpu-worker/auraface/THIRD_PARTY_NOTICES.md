# AuraFace CPU runner third-party notices

This private candidate image contains the InsightFace Python package
`1.0.1`. The upstream project states that its Python code is released under
the MIT License. ReeditPro does not use or distribute any pretrained model
provided by the InsightFace project.

The runner accepts only the separately pinned `fal/AuraFace-v1` ONNX
artifacts described in the Living Frame artifact-requirement contract. The
AuraFace publisher labels those artifacts Apache-2.0. That label is controlled
supply-chain evidence, not independent proof of training-data rights,
fairness, consent, or production qualification.
