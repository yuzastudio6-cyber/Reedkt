## Embedded Observation

The image installs one fixed executable:

`/usr/local/bin/reeditpro-remotion-cgroup-resource-observer`

The server, not the caller, replaces the container entrypoint with that
observer and supplies only a fresh 48-character nonce plus the allowlisted
`/usr/local/bin/node /app/runner.mjs` command. The container remains non-root,
network-none, read-only, capability-free, no-new-privileges, bounded to 256
processes, 2 vCPU, 4 GiB memory/swap, fixed tmpfs/shm, no bind mount, no caller
environment, and no caller executable or command.

The observer reads only cgroup-v2 `cpu.stat`, `memory.current`, and
`memory.peak`. It emits one nonce-bound terminal marker after the child exits.

malformed, non-monotonic, overflowed, wrong-container, wrong-image, or
wrong-agent evidence. It removes the marker before the existing zero-stderr
success rule is applied. The normalized observation hashes the private
container identity rather than persisting the raw container ID.
