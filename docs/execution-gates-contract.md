# Execution Gates Contract

This file defines reusable production gates for future backend, worker, provider, render, storage, credit, and tool milestones. It is a docs-only contract and does not implement any gate.

User-facing message style should be clear, specific, and non-technical: state what is missing, what the user can do next if action is possible, and avoid exposing internals, secrets, stack traces, or provider payloads.

| Gate | Purpose | Checked by | Required records | Pass condition | Fail condition | Failure status | User-facing message style | Audit event | Future implementation notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `AuthGate` | Confirm the caller is authenticated. | Backend API middleware. | Auth session/user ID. | Valid authenticated user. | Missing/expired/invalid auth. | `auth_required` | Ask user to sign in again. | `gate.auth.failed` | Frontend may display auth state but cannot bypass backend auth. |
| `WorkspaceGate` | Confirm workspace membership and role. | Backend API/service-role path. | `workspaces`, `workspace_members`. | Active member with required role. | No workspace, inactive member, insufficient role. | `workspace_forbidden` | State the workspace is unavailable or access is missing. | `gate.workspace.failed` | RLS should mirror read boundaries; backend owns privileged checks. |
| `ProjectAccessGate` | Confirm project access and edit/export permission. | Backend API. | `projects`, membership, project role/status. | Caller can perform requested project action. | Missing project, wrong workspace, insufficient permission. | `project_forbidden` | State the project cannot be accessed for this action. | `gate.project_access.failed` | Required for chat, upload, plan, approval, jobs, preview, export. |
| `IdempotencyGate` | Prevent duplicate mutations and duplicate expensive work. | Backend API. | `api_idempotency_keys`, request hash. | New key or same key with same request hash. | Missing key, reused key with different request, active duplicate. | `idempotency_blocked` | Ask user to retry safely or wait for current request. | `gate.idempotency.failed` | Required for create/update mutations that affect cost, jobs, storage, snapshots, provider attempts, or exports. |
| `UploadIntentGate` | Ensure uploads start from a validated intent. | Backend API/storage service. | `upload_intents`, project/workspace records. | Intent exists, belongs to project, is active, and file constraints match. | Missing/expired/mismatched intent. | `upload_intent_invalid` | Explain the upload needs to be restarted. | `gate.upload_intent.failed` | Upload intent does not equal canonical media readiness. |
| `StorageObjectGate` | Confirm canonical private storage records exist. | Backend API/worker. | `storage_object_records`, `media_assets`. | Required bucket/path records exist, are private, and belong to project/workspace. | Missing records, signed URL used as source truth, wrong project, unsafe path. | `storage_object_missing` | State required media or asset is not ready. | `gate.storage_object.failed` | Canonical records store bucket/path only. |
| `MediaReadinessGate` | Confirm media has been probed and is usable. | Backend API/worker. | `media_assets`, probe/readiness records. | Required source media status is ready with valid duration/frame data. | Probe missing, failed, unsupported, or incomplete. | `media_not_ready` | State source media is still processing or unsupported. | `gate.media_readiness.failed` | Required before transcript, timing, planning execution, render, or export paths that depend on source media. |
| `PlanApprovalGate` | Confirm edit plan approval. | Backend API. | `edit_plans`, approval records. | Plan is approved and current for requested project/version. | Draft, stale, rejected, changed, or unapproved plan. | `plan_not_approved` | Ask user to approve the plan or review changes. | `gate.plan_approval.failed` | Plan changes reset downstream approval where material. |
| `CreditEstimateApprovalGate` | Confirm the credit estimate was approved. | Backend API/credit service. | `credit_estimates`, `credit_approvals`. | Estimate is accepted/approved and matches plan/snapshot scope. | Missing, expired, stale, rejected, or mismatched estimate. | `credit_estimate_not_approved` | Ask user to approve the latest estimate. | `gate.credit_estimate.failed` | Subscriptions do not imply unlimited AI work. |
| `CreditReservationGate` | Confirm active reserved credits when credits apply. | Backend API/credit service/worker. | `credit_reservations`, wallet/ledger records. | Active reservation covers the requested operation scope and amount. | Missing, released, spent, refunded, insufficient, or mismatched reservation. | `credit_reservation_missing` | State credits must be reserved before work can start. | `gate.credit_reservation.failed` | Required for generation, render, export, and generation-mode audio/tool/provider work. |
| `ApprovedSnapshotGate` | Confirm workers execute a frozen approved snapshot. | Backend API/worker. | `approved_plan_snapshots`. | Snapshot exists, approved, immutable, current for job scope, and includes required frozen policies. | Missing, draft, stale, invalid, or changed snapshot. | `approved_snapshot_missing` | Ask user to approve the latest plan snapshot. | `gate.approved_snapshot.failed` | Workers must never execute raw chat. |
| `TimingValidationGate` | Confirm frame/timing context is valid. | Backend API/planner/render service. | `MasterTimingPlan`, timing validation records, approved snapshot. | Timing validation passes and frame/aspect context is confirmed. | Missing frame, missing timing, blocking timing validation, or material timing change. | `timing_validation_blocked` | State timing/frame choices need review before generation or export. | `gate.timing_validation.failed` | Required before snapshot approval and render/export readiness. |
| `ToolRuntimeReadinessGate` | Confirm required tool runtime availability. | Backend API/worker readiness service. | `tool_runtime_checks`, runtime profile. | Required tool is available in approved worker profile. | Missing, unavailable, wrong version, disabled, or unverified runtime. | `tool_runtime_unavailable` | State the required processing tool is unavailable. | `gate.tool_runtime.failed` | Readiness checks are not tool execution. |
| `ToolLicenseComplianceGate` | Confirm tool/license/security approval. | Backend API/compliance service. | Tool registry, license/security review records. | Tool route is approved for the requested production use. | Blocked, evaluation-only, unknown license, or missing review. | `tool_compliance_blocked` | State the requested tool path is not approved for production yet. | `gate.tool_compliance.failed` | Must block even if runtime binary is available. |
| `ProviderReadinessGate` | Confirm provider route can run safely. | Provider gateway/backend API. | Provider config, model/tier policy, secret reference, approved snapshot, reservation. | Provider enabled, secret available, model/tier allowed, and request matches approved snapshot. | Missing secret, disabled provider, unsupported tier/model, missing gates. | `provider_not_ready` | State the provider path is unavailable and offer approved alternatives when possible. | `gate.provider_readiness.failed` | Basic/Pro never use Veo; Premium uses Veo only as final fallback/rescue. |
| `WorkerClaimGate` | Ensure one worker owns the job. | Backend API/worker claim service. | `jobs`, `worker_job_claims`, dependency records. | Job is claimable and one active claim is created/held. | No claim, duplicate active claim, blocked dependencies, terminal job. | `worker_claim_blocked` | State work is waiting for a worker slot or dependency. | `gate.worker_claim.failed` | Required before worker execution. |
| `WorkerHeartbeatGate` | Confirm active worker progress is alive. | Backend API/worker service. | `worker_job_claims`, heartbeat/lease records. | Heartbeat is current and claim is valid. | Missing/stale heartbeat or expired claim. | `worker_heartbeat_stale` | State the job is being retried or recovered. | `gate.worker_heartbeat.failed` | Stale recovery must be idempotent. |
| `RenderReadinessGate` | Confirm render inputs are complete. | Render service/backend API/worker. | Approved snapshot, render manifest, assets, storage records, timing, QA prereqs. | All required assets and manifest inputs are ready. | Missing asset, placeholder in final export, missing timing, unresolved dependency. | `render_not_ready` | State preview/export is waiting on required assets. | `gate.render_readiness.failed` | Preview may use placeholders only when approved; final export cannot. |
| `QABlockerGate` | Prevent export when required QA fails. | QA service/render/export service. | `qa_reports`, QA issue records, approved snapshot. | No blocking QA issues remain. | Blocking QA issue, failed required check, unresolved required failure. | `qa_blocked` | State the result needs review or correction before export. | `gate.qa_blocker.failed` | QA failures can trigger approved fallback or user review. |
| `RevisionApprovalGate` | Ensure material revisions are approved. | Backend API/planning service. | `revision_requests`, edit plan versions, credit estimates, snapshots. | Revision is non-material or new plan/estimate/snapshot is approved. | Material revision without new approval. | `revision_requires_approval` | Ask user to approve the revised plan and estimate. | `gate.revision_approval.failed` | Material changes reset approval, progress, preview readiness, and snapshot readiness. |
| `ExportReadinessGate` | Confirm final export can start or complete. | Export service/backend API/worker. | Render, QA, approved snapshot, credit reservation, storage/export records. | Approved snapshot, ready final render, QA pass, storage target, and credit gates pass. | Missing render, blocking QA, missing storage, unresolved revision, missing reservation. | `export_not_ready` | State export is not ready and list the blocking category. | `gate.export_readiness.failed` | Final export cannot start with placeholders or unresolved required failures. |
