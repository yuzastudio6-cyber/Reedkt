# Edit Level UI Cards

RP-EDITLEVEL-04 makes Edit Level UI cards visible in the product-facing mock/local setup flow. The cards show Normal, Premium, and Ultra Premium with user-facing copy, best-for guidance, included highlights, Edit Brief guidance, estimate-only notes, and selected/recommended states.

Normal remains a clean professional edit, not a low-quality option. Premium is an enhanced creative edit. Ultra Premium is a studio-level creative treatment.

The UI cards are visible, but selection is still mock/local. There is no live planner routing change, no provider call, no worker, no render/export, no credit spend, and no production persistence.

Credit estimate only copy is visible on the cards and estimate notice. Render/revision budget is future metadata.
