# OCR Model License Evidence Policy

Phase 37A records package, runtime, and model-family evidence separately. PaddleOCR and PaddlePaddle are recorded from official repositories with Apache-2.0 license claims. PP-OCRv5 is recorded as a model-family candidate, but exact detection, recognition, and classifier assets are deferred to Phase 37B.

Phase 37B must record exact official model asset URLs, versions, filenames, checksums, and private GCS upload evidence before any runtime verification. Project/package license evidence is not enough to permit runtime auto-download or unpinned model assets.
