# Render Readiness Gate Contract

These gates define the reusable contract future render/export workers must enforce before any expensive work begins.

| Gate | Purpose | Checked by | Required records | Pass condition | Fail condition | Failure status | User-facing message style | Audit event | Future notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| AuthGate | Ensure caller is authenticated. | Route middleware | Auth session | User context exists. | Missing/invalid session. | `blocked` | Ask user to sign in. | `render.auth_blocked` | Keep auth separate from service-role runtime. |
| WorkspaceGate | Scope request to workspace. | Project access service | `workspaces`, `workspace_members` | Project belongs to workspace. | Workspace mismatch. | `blocked` | Say project is not accessible. | `render.workspace_blocked` | Never reveal cross-workspace IDs. |
| ProjectAccessGate | Confirm membership access. | Project access service | `projects`, `workspace_members` | Caller is a member/editor as required. | Non-member or missing project. | `blocked` | Say project is unavailable. | `render.project_access_blocked` | Reuse Prompt 3 path. |
| ApprovedSnapshotGate | Require immutable approved plan. | Render service | `approved_plan_snapshots` | Snapshot exists and is approved/ready. | Missing or not approved. | `blocked` | Ask user to approve the plan first. | `render.snapshot_blocked` | Workers execute snapshots, not raw chat. |
| CreditEstimateApprovalGate | Confirm approved estimate. | Render/credit service | `credit_estimates` | Estimate is approved/accepted when required. | Missing or not approved. | `blocked` | Ask user to approve credit estimate. | `render.credit_estimate_blocked` | Do not mutate credits in render service. |
| CreditReservationGate | Confirm active reservation. | Render/credit service | `credit_reservations` | Reservation is active/reserved. | Missing, released, spent, or mismatched. | `blocked` | Explain credit reservation is required. | `render.credit_reservation_blocked` | Real reserve/spend remains Prompt 6 future work. |
| MediaReadinessGate | Confirm source media metadata exists. | Render/media service | `media_assets` | Metadata required for render exists. | Missing content, duration, frame, or readiness. | `blocked` | Ask user to finish media readiness. | `render.media_blocked` | No media analysis in Prompt 10. |
| StorageObjectGate | Confirm canonical storage references. | Render/storage service | `storage_object_records` | Bucket/path source records exist and are private. | Missing object record or invalid path. | `blocked` | Explain source assets are not storage-ready. | `render.storage_blocked` | Signed URLs are events, not truth. |
| SourceSequenceGate | Confirm source order is known. | Media readiness service | `uploaded_clips`, `source_sequence_items` | Source order is confirmed when needed. | Missing/unconfirmed sequence. | `blocked` | Ask user to confirm source order. | `render.source_sequence_blocked` | Render must preserve approved source order. |
| TimingManifestGate | Confirm approved timing reference. | Render service | `master_timing_maps` or approved timing manifest | Timing exists and matches frame/aspect context. | Missing timing manifest. | `backend_required` | Explain timing validation is required. | `render.timing_blocked` | Frame-accurate timing remains future worker/runtime. |
| TimingValidationGate | Confirm timing QA passed. | Future QA service | Timing validation records | Blocking timing issues absent. | Timing validation failed or missing. | `backend_required` | Explain timing needs validation. | `render.timing_validation_blocked` | Speech clarity and captions must remain protected. |
| CaptionReadabilityGate | Prevent unreadable captions. | Future QA service | Caption/timing QA records | No blocking readability issues. | Caption collision/readability failure. | `backend_required` | Explain captions need QA. | `render.caption_blocked` | Required before final export. |
| QAReportGate | Confirm QA summaries can be checked. | Render service | `qa_reports`, `qa_check_results` | QA records are available or not required for preview. | QA unavailable. | `backend_required` | Explain QA validation is required. | `render.qa_required` | Prompt 10 reads only. |
| QABlockerGate | Block final output on QA failure. | Render service | `qa_reports`, `qa_check_results` | No blocking QA statuses. | Blocking QA exists. | `blocked` | Explain final export cannot proceed. | `render.qa_blocked` | Prompt 11 deepens QA/revision behavior. |
| RenderManifestGate | Validate manifest shape. | Render service | Manifest DTO and referenced records | Manifest is deterministic and secret-free. | Missing refs or unsafe metadata. | `blocked` | Ask user to resolve manifest blockers. | `render.manifest_blocked` | Manifest build does not execute Remotion. |
| RenderJobIdempotencyGate | Prevent duplicate render requests. | Idempotency middleware | `api_idempotency_keys` | Mutation request has valid key. | Missing/replayed conflict. | `blocked` | Ask user to retry safely. | `render.idempotency_blocked` | Required for preview/export requests. |
| RenderWorkerRuntimeGate | Confirm render worker exists. | Render service/future worker claim | Worker runtime/claim records | Reviewed worker runtime is available. | Runtime missing. | `backend_required` | Explain render runtime is not enabled. | `render.worker_backend_required` | Prompt 10 always blocks execution. |
| RemotionRuntimeGate | Confirm compositor runtime. | Future render worker | Remotion worker config | Runtime is available and reviewed. | Missing/unavailable Remotion. | `backend_required` | Explain Remotion is not enabled. | `render.remotion_backend_required` | Do not run in API route. |
| FFmpegPostprocessGate | Confirm export/postprocess runtime. | Future export worker | FFmpeg runtime config | Runtime is available and reviewed. | Missing/unavailable FFmpeg. | `backend_required` | Explain export runtime is not enabled. | `render.ffmpeg_backend_required` | Legal/config review required. |
| ExportFormatGate | Validate output format. | Render service | Request DTO | Format is supported and approved. | Unsupported format. | `blocked` | Ask user to choose supported export format. | `export.format_blocked` | Prompt 10 supports schema validation only. |
| ExportStorageGate | Confirm private export storage path. | Future export service | `storage_object_records`, `final_exports` | Private bucket/path target exists. | Missing storage target. | `backend_required` | Explain export storage is not ready. | `export.storage_backend_required` | No signed URL generation in Prompt 10. |
| WorkerExecutionBlockedGate | Ensure no worker starts early. | Render service/diagnostics | N/A | Worker execution disabled in Prompt 10. | Attempted worker execution. | `blocked` | Explain execution is future milestone. | `render.worker_execution_blocked` | Diagnostics must fail on worker calls. |
| ProviderExecutionBlockedGate | Ensure providers are not called. | Render service/diagnostics | N/A | Provider calls disabled. | Attempted provider call. | `blocked` | Explain providers are not part of render foundation. | `render.provider_execution_blocked` | Provider gateway remains future. |
| ToolExecutionBlockedGate | Ensure tools do not run. | Render service/diagnostics | N/A | Tool execution disabled. | Attempted tool execution. | `blocked` | Explain tools remain future worker-only. | `render.tool_execution_blocked` | Tool execution requires future compliance/runtime. |
