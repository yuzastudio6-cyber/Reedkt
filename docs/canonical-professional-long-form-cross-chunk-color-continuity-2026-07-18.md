## Fixed runtime policy

The runtime uses the existing server-injected policy:

- policy: `bt709_adjacent_chunk_boundary_rgb_policy_v1`;
- recipe: `approved_cross_chunk_color_continuity_rgb_sample_v1`;
- 30-frame sample window;
- three decoded RGB samples per side;
- technical-split mismatch blocks finalization;
- editorial-cut mismatch requires review;
- media mutation is forbidden; and
- runtime confinement requires no network, read-only root filesystem,
  `65532:65532`, all capabilities dropped, and no-new-privileges.

The canonical service accepts only a passed runtime result. Any failed or
review-required boundary prevents queue completion.
