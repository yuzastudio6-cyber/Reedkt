# Phase 44E Desktop Capability Fixtures

Phase 44E uses generated/mock desktop profiles only:

- `fixture-desktop-high-local`
- `fixture-desktop-mid-no-ffmpeg`
- `fixture-desktop-low-resource`
- `fixture-electron-sandboxed-renderer`
- `fixture-unknown-desktop`

The fixtures validate route hints such as local-processing candidate, server-worker preferred, ffmpeg unavailable, sandbox bridge required, low-resource avoidance, and unknown-capability fail-closed behavior.

No live desktop profile is required for Phase 44E readiness.
