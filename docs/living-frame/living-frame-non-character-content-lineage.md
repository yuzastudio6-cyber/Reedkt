# Living Frame Non-Character Content Lineage

## Purpose

`living-frame-non-character-content-lineage-v1` is the source-only boundary
for four active representative Living Frame content routes:

1. a verified map or route inside Living A-Roll;
2. a readable archive-document composition;
3. an exact diagram built from approved rows and relationships; and
4. a non-character hybrid expansion that enters and returns through the
   selected scene's canonical MasterTiming interval.

The contract does not approve, execute, render, persist, or review a scene. It
proves that a prospective scene is structurally bound to the existing planning
and execution owners before the canonical backend admits it.

## Existing Owners Reused

The compiler reads the existing `MapAnimationPlan`, `DataVizPlan`,
`DocumentaryFactSafetyPlan`, and `ApprovedToolWorkSourceReferences` types. It
does not copy them into a new authority.

Each case also carries digest-only references to:

- the exact selected-scene binding;
- immutable approved snapshot and confirmed output frame;
- canonical MasterTiming and motion interval;
- approved Living Frame lineage;
- estimate/cost, work-graph, exact work/output, and asset-manifest/entry
  projections;
- renderer binding and layer manifest;
- scene-evidence package; and
- required deterministic QA, postrender AI visual-inspection, and canonical
  private-review assembly.

It additionally requires an exact ordered, role-tagged source-evidence set:
coordinate and route refs for maps, document and OCR/excerpt refs for archives,
approved row refs for diagrams, and source-content refs for the hybrid
takeover. These are namespaced structural refs only; the canonical backend must
still reread and admit the immutable source objects.

Canonical approved-snapshot reread, source/citation admission, work-graph and
asset-manifest reconciliation, renderer execution, deterministic QA, Qwen
postrender evidence, Head QA recommendation, and private review remain pending
with their existing owners.

## Byte-Free Projection

The emitted binding contains hashes, IDs, versions, counts, confidence/claim
status summaries, and controlled route identities only. It intentionally omits:

- map coordinates;
- data labels and values;
- archive OCR or excerpts;
- documentary claims;
- raw chat or transcript;
- media bytes;
- paths, URLs, credentials, commands, and environment data.

Workers must reread the exact approved source records through canonical
authority. They must never reconstruct visible content from this summary.

## Route Rules

### Map and hybrid

Locations must be exact and verified, have source labels and safe wording, and
carry complete deterministic route geometry whose start and destination match
the approved source locations. The approved route uses the
existing `d3`, `svg_js`, and `remotion` identities. AI video may not own map
coordinates, labels, or route truth. Hybrid entry, takeover, and return remain
inside the selected-scene and MasterTiming motion interval; there is no hybrid
clock.

### Archive document

The plan must use an uploaded-document source, source-labelled records, and no
mock, fictional, or unknown data. The controlled route uses existing `satori`,
`svg_js`, and `remotion` identities. Visible OCR, excerpts, dates, and claims
must be reread from the approved document and inspected after render.

### Exact diagram

The plan must use verified user-provided data with a source label on every
record. The controlled cause-and-effect route uses existing `viz_js`,
`svg_js`, and `remotion` identities. AI video cannot own exact labels, values,
units, or relationships.

No new tool identity is created by this contract.

## Fail-Closed Behavior

Compilation rejects:

- approximate, unknown, fictional, or source-needed map locations;
- missing or invalid route geometry;
- mock, fictional, unknown, or uncited archive/diagram records;
- unresolved, unknown, or fictional documentary claims in these source-bound
  cases;
- fake or substituted tool routes;
- wrong selected-scene mode;
- malformed or substituted timing lineage;
- missing approved work/source references; and
- unexpected fields that could smuggle raw source content.

The focused smoke exercises four controlled cases and twenty-three adversarial
rejections.

## Owner Pause

This boundary does not admit living or organic animation, complete-character
keyposes or interpolation, living-subject rigs, or mechanical rigging. Static
illustrations may remain unanimated. Those paths require a future explicit
owner specification.

## Current Status

Source contract and feature-level verification are implemented. Canonical
approved reread, work admission, execution, asset persistence, postrender
visual inspection, Head QA, and private review remain false. Runtime,
dispatch, billing, public delivery, and production authority are not granted.
