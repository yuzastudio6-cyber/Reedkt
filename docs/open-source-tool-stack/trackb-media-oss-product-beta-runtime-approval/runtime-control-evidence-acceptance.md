# Runtime Control Evidence Acceptance

Accepted source-truth control evidence:
- Fail-closed route runtime controls.
- Per-tool worker dispatch allowlists.
- Approved snapshot, edit-plan, and credit gates.
- Service-role/no-write boundary.
- Sanitized monitoring.
- Rollback disable controls.
- Limited internal exposure rules.

This evidence is accepted for controlled activation execution planning only; it does not run or enable live product calls.
