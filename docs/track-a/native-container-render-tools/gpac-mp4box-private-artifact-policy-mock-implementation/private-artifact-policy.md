# Private Artifact Policy

The private artifact policy is metadata-only.

It records policy id `artifactPolicy.gpacMp4box.private.mock`, storage access mode `metadata_only_no_storage_transfer`, artifact scope `worker_temp_private_only`, checksum algorithm `sha256`, and cleanup required `true`.

It does not write storage, create signed URLs, create public artifacts, run GPAC/MP4Box, process media, mutate Supabase, run SQL, or unlock beta/production/final delivery.
