# Reference-Video Analysis

## Availability

The conversation described uploaded reference videos, but their raw files were not available to this CAP-00 run. No hash, codec, duration, frame sample, timestamp annotation, or creator-specific verification is claimed.

## Canonical observed patterns

The pasted goal records these reusable patterns:

- spatial sentence assembly;
- multiple simultaneous caption tracks;
- speaker surrounded by text;
- persistent topic/list typography;
- captions sharing the frame with B-roll;
- caption mode switching within one video;
- text behind and in front of subjects;
- object/environmental anchors;
- hero/full-screen typography;
- caption-to-map/diagram/brush/route/transition/Living Frame handoffs.

These are design principles and test cases, not exact designs to copy.

Each annotation should include source timestamp/frame, observation, confidence, caption role, integration class, track/depth structure, semantic/motion/sound behavior, occupancy relationship, reusable principle, forbidden literal-copy detail, and relevance to a CAP milestone.
