# Phase 36M Demucs Exclusion Policy

Demucs is excluded from the Phase 36M restricted internal audio/timing scope.

Phase 36K records MIT source/package evidence but keeps Demucs blocked pending training-data provenance, model-weight/artifact provenance, and human/legal review. Phase 36M treats that block as an explicit internal-scope exclusion, not as permission to install Demucs, download weights, stage models, or run source separation.

Blocked Demucs scopes:

- package installation
- model or weight download
- private model staging
- runtime execution
- source separation
- Phase 36L execution without a later human/legal approval

Any future product-wide beta decision must explicitly accept Demucs exclusion for the current internal scope or require later Demucs approval/runtime phases before broadening the audio/timing tool family.
