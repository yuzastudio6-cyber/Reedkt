# Phase 44F Desktop Benchmark Privacy Policy

Phase 44F blocks:

- persistent device identifiers
- hostname, username, MAC addresses, and serial numbers
- exact CPU/GPU identifiers
- environment variable dumps
- process lists and installed app scans
- user directory scans and arbitrary file paths
- media files
- network benchmarks
- GPU benchmarks
- sustained CPU stress tests and long memory pressure tests
- local persistence by default
- live benchmark upload

Local benchmark execution requires explicit current-shell confirmation and remains generated-data-only, bounded, temporary, and non-uploading.
