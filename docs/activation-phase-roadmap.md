# Activation Phase Roadmap

Phase 18 starts the post-M17 activation track. Milestones 0-17 built the dry-run/static production runtime foundation. Activation moves that foundation toward human-run staging setup and controlled real video testing, one gate at a time. Phase 19 is the current local baseline step before any Phase 20 container build preparation.

This roadmap is not launch approval. Production-ready, external beta, paid production, and real user media remain blocked until the later gates explicitly pass. Codex must not build Docker images, push images, run `gcloud`, deploy, call providers, download model weights, add secrets, or process real media in Phase 18.

## Phases 18-37

| 18. | 19. | 20. | 23. | 24. Deploy staging API and non-GPU worker jobs | Deploy API, CPU, render, and QA staging paths. | Validates non-GPU runtime, private storage, and worker shape before GPU. | `scripts/gcp/prod/08-09-11-12-*.example.sh`. | Deploy reviewed staging services/jobs manually. | Staging-only deployment exists; real providers/user media remain disabled. | No GPU worker, external beta, or production launch. |

| 28. | 31. | 32. Controlled actual video test: color correction | Validate color correction on controlled private media. | Protects exposure, skin tone, and export color before broader use. | Real color execution runbook and workers. | Run color correction after prior staging readiness gates. | Color QA passes or blocks; private artifacts only. | No public delivery or QA bypass. |
| 33. | 34. | 35. Full actual video E2E, private beta candidate | Run one full private actual-video E2E after controlled tests. | Determines whether internal beta can be considered. | Full E2E workflow reports and scenario matrix. | Run full private E2E with approved test media and signoffs. | Required QA, storage, cost, security, fallback, and delivery blockers pass. | Do not call this external beta or paid production. |
| 36. Limited internal beta readiness | Evaluate limited internal beta. | Internal beta needs operational, support, legal, and privacy readiness beyond technical pass. | Beta readiness scorecard/runbook. | Review operational ownership and internal-only scope. | Kill switches, cost controls, privacy, support, and rollback are ready. | No external beta. |
| 37. External beta go/no-go | Make the strict external beta decision. | External beta needs complete evidence and human approval. | Go/no-go checklist and beta/hardening reports. | Review final go/no-go with required owners. | Deployment, rollback, model/license, security, cost, privacy, storage, legal, and support approvals complete. | Do not approve paid production by default. |

Real video testing begins only at Phase 28, and only after staging deployment, storage/readiness validation, and model/license prerequisites pass.
