# Phase 45E Full Visual-Video Private E2E QA Policy

Mandatory QA gates:

- `source_integrity`
- `phase45a_libass_evidence`
- `phase45b_remotion_evidence`
- `phase45c_otio_evidence`
- `phase45d_ffmpeg_ffprobe_evidence`
- `private_review_export_integrity`
- `ffprobe_review_export_validation`
- `evidence_manifest_created`
- `artifact_privacy`
- `no_public_access`
- `no_final_delivery`
- `blocked_features`

Track A visual-video internal testing readiness is true only when all mandatory gates pass. The readiness does not authorize final delivery, production, external beta, paid production, broad real media, providers, Revideo, or Track B.
