- Demucs download/runtime/source separation
- model weight staging
- torch hub or runtime auto-download
- media/audio processing
- broad or arbitrary media
- unapproved real media
- public artifacts or public output
- provider calls

- internal beta unlock, external beta, paid production, production

- safe report generation
- future handoff prompt drafting
