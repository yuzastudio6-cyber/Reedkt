## Owner Rules

| Owner | Primary responsibility | SOUND role |
| --- | --- | --- |
| `SOUND_MUSIC_AUDIO` | Audio planning, SoundSync cue planning, SFX/music planning semantics, audio QA evidence, private audio artifact manifests | own when the tool is audio-planning or audio-candidate scoped |
| `TRACK_A_RENDER_EXPORT` | Final render, export, mux, captions burn-in, render/timeline handoff | reference-only or handoff-only |
| `TRACK_B_MEDIA_PROCESSING` | General media processing, visual/audio analysis infrastructure, private QA metadata | reference-only or handoff-only |
| `AI_TOOLS_CREATIVE_GRAPHICS` | Graphics, dataviz, motion/canvas tooling, exact cards/charts | reference-only |
| `WEB_SEARCH_CAPTURE` | Browser capture and web-source tooling | reference-only |
| `MAP_GEOSPATIAL` | Map, geo, route, and geospatial visualization tooling | reference-only |
| `PROVIDER_GATEWAY_MODELS` | Real provider transport, provider secrets, fallback policy, model/provider clients | handoff-only |
| `WORKER_RUNTIME_JOBS` | Dispatch, claim, lease, worker runtime, Cloud Run orchestration | handoff-only |
| `SUPABASE_RLS_STORAGE_DATABASE` | Supabase persistence, RLS, storage, migrations, signed URL policy | handoff-only |
| `OBSERVABILITY_AUDIT_COST` | Audit, observability, cost metadata, evidence rollups | handoff-only |
| `BILLING_STRIPE_CREDITS` | Credit reservation/spend/refund, Stripe/payment flows | handoff-only |
| `TOOL_ROUTE_EXECUTION` | Tool-route dry-run planning, contracts, validation, owner approvals | reference-only |

## Reference-Only Or Handoff-Only Tools

SOUND must not duplicate ownership for Track A render/export, Track B media processing, AI graphics, Web Search, Map/Geospatial, Provider Gateway, Worker Runtime, Supabase, Observability, or Billing tools. SOUND may only consume their metadata, write handoff expectations, or route future prompts to the primary owner.
