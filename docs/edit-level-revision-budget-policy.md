# Edit Level Revision Budget Policy

RP-EDITLEVEL-09 exposes future revision budget metadata for product planning copy.

| Level | Future revision budget |
| --- | ---: |
| Normal | 1 |
| Premium | 2 |
| Ultra Premium | 3 |

This does not create a service promise, production revision entitlement, credit reservation, worker job, render job, or approved plan version. Revision budget items are future-gated estimate metadata and remain `needsProductValue` where product pricing or package policy is still unsettled.

Future implementation must connect revision policy to approved snapshots and credit estimate approval before any production execution occurs.
