## Honest remaining gates

The final release manifest distinguishes:

- qualified Caption-owned jobs;
- qualified injected dependency fixtures;
- missing shared-owner integration;
- external model/font/license/deployment gates;
- public/billing/production gates.

No source-only contract, historical untracked result, bounded fixture, or
technical-only raster check may be relabeled as full private qualification.
Direct sampled-frame inspection is required and valid, but it may not be
relabeled as qualified complete-time visual-AI review.

## CAP-00R acceptance

CAP-00R passes when:

- historical CAP-00 docs are present with this amendment;
- the clean base and dirty preservation paths are recorded exactly;
- owner/public-boundary, gap, duplicate-lane, keep/adapt/retire, migration,
  compatibility, and CAP-00R evidence documents exist;
- CAP-00R points to the CAP-00R–20 roadmap;
- links, prohibited stale claims, Git diff scope, and repository instructions
  pass;
- only documentation changed and no runtime/provider/media/migration/billing/
  secret/deployment action occurred;
- the checkpoint is committed and pushed.

Passing CAP-00R authorizes automatic continuation to CAP-01. It does not grant
execution, provider, billing, QA approval, public delivery, or production
authority.
