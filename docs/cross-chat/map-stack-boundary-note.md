# Map Stack Boundary Note

Status: `docs_only`.

Map/geospatial ownership belongs to another chat.

This AI Tools / Creative Graphics chat must not claim ownership of:

- MapLibre
- Turf
- deck.gl
- CesiumJS
- PMTiles
- TileServer GL
- Martin
- Nominatim
- Photon
- Pelias
- OSRM
- Valhalla
- Live tile provider policy
- Geocoding/routing runtime policy

Allowed integration with AI Tools is limited to approved artifacts and manifests such as source records, location candidates, GeoJSON, style/camera/timing manifests, private map QA references, and render-ready handoff records.

AI Tools may design graphic treatment around approved map artifacts, but it does not own map data, map runtime, live tiles, geocoding, routing, or map provider policy.
