# Activation Enhancement Model License Evidence Policy

Enhancement and slow-motion model weights require evidence records before download, runtime verification, production review, or broad real-media use.

Evidence records must keep repository/package licensing separate from model-weight and release-asset evidence. A permissive code license, such as BSD-3-Clause for Real-ESRGAN or Apache-2.0 for FILM, can support staging review, but it does not automatically approve every model file, release asset, checkpoint mirror, runtime package, or production use.

Required evidence fields:

- source name and URL
- source type: GitHub, Hugging Face, package registry, release asset, docs, or manual review
- license claim
- commercial-use and redistribution claim
- attribution requirements
- reviewed/fetched date
- confidence
- notes and risk scope

Phase 34A records Real-ESRGAN repository and release-asset evidence for `RealESRGAN_x4plus`, but checksum and exact file evidence are still missing until Phase 34B. FILM evidence is recorded as evaluated-only and blocked for download/execution.
