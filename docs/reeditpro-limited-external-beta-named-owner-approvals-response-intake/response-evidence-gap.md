# Response Evidence Gap

The missing evidence is not a tooling or diagnostic failure. It is an absent owner response problem.

The next submission must include owner name, owner role, owner slot, approval decision, approved or rejected scope, timestamp, accepted duty or rejection reason, explicit exclusions, and evidence reference.

Legacy cross-workstream owner-response ledgers, previous metadata readiness, passing diagnostics, placeholder names, generic readiness wording, and implicit consent are not valid substitutes.
