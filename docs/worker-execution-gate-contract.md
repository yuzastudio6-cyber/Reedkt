# Worker Execution Gate Contract

| Gate | Purpose | Checked by | Required records | Pass condition | Fail condition | Failure status | User-facing message style | Audit event | Future notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| AuthGate | Require authenticated caller. | Backend API | Auth session | User context exists. | Missing/invalid auth. | `blocked` | Ask user to sign in. | `workers.auth.blocked` | Worker auth differs from user auth later. |
| WorkerAuthGate | Require trusted worker identity. | Backend API/future worker runtime | Worker identity | Worker is verified. | Missing worker trust. | `backend_required` | Worker runtime unavailable. | `workers.worker_auth.blocked` | Add signed worker identity later. |
| WorkspaceGate | Scope work to workspace. | Backend API | `workspaces`, `workspace_members` | Caller is workspace member. | Not member. | `blocked` | Project is not accessible. | `workers.workspace.blocked` | Enforce RLS and service checks. |
| ProjectAccessGate | Scope work to project. | Backend API | `projects`, `workspace_members` | Project belongs to accessible workspace. | No access/mismatch. | `blocked` | Project is not accessible. | `workers.project.blocked` | Prompt 3 service is current boundary. |
| ApprovedSnapshotGate | Ensure immutable plan input. | Backend API | `approved_plan_snapshots` | Approved snapshot exists. | Missing/unapproved. | `blocked` | Edit plan must be approved. | `workers.snapshot.blocked` | Workers must not use raw chat. |
| CreditEstimateApprovalGate | Ensure approved estimate. | Backend API | `credit_estimates`, `approval_records` | Approved estimate exists. | Missing/unapproved. | `blocked` | Credit estimate must be approved. | `workers.credit_estimate.blocked` | Prompt 6 mutation remains blocked. |
| CreditReservationGate | Ensure active reservation. | Backend API | `credit_reservations` | Reservation active and scoped. | Missing/inactive. | `blocked` | Credits must be reserved. | `workers.credit_reservation.blocked` | Required when credits apply. |
| MediaReadinessGate | Ensure source media facts. | Backend API | `media_assets` | Media ready when needed. | Missing/not ready. | `blocked` | Media is not ready. | `workers.media.blocked` | Prompt 9 is readiness-only. |
| StorageObjectGate | Ensure canonical storage refs. | Backend API | `storage_object_records` | Bucket/path records exist. | Missing or signed URL-only. | `blocked` | Storage record is not ready. | `workers.storage.blocked` | Signed URLs are never source of truth. |
| TimingReadinessGate | Ensure timing context. | Backend API | timing records | Timing ready when needed. | Missing timing. | `blocked` | Timing is not ready. | `workers.timing.blocked` | Future timing worker required. |
| QABlockerGate | Block unresolved QA issues. | Backend API | `qa_reports`, blockers | No blocking QA. | Blocking QA exists. | `blocked` | QA blockers must be resolved. | `workers.qa.blocked` | Prompt 11 remains fail-closed. |
| ToolCallIntentGate | Require approved tool intent. | Backend API | `tool_call_intents` | Tool intent approved/scoped. | Missing/unapproved. | `blocked` | Tool call intent is not ready. | `workers.tool_intent.blocked` | Prompt 12 does not persist intents. |
| ToolReadinessGate | Require static readiness. | Backend API | Prompt 13 registry | Tool classified and allowed for future path. | Missing/blocked state. | `blocked` | Tool is not ready. | `workers.tool_readiness.blocked` | Static only in Prompt 14. |
| ToolRuntimeDisabledGate | Keep runtime disabled. | Backend API | Prompt 13 policy | Always blocks execution in Prompt 14. | Runtime requested. | `blocked` | Tool runtime is disabled. | `workers.tool_runtime.blocked` | Future activation must update policy. |
| WorkerRuntimeGate | Require transactional runtime. | Backend API | worker runtime config | Runtime reviewed and enabled. | Missing runtime. | `backend_required` | Worker runtime unavailable. | `workers.runtime.blocked` | No Cloud Run dispatch now. |
| WorkerClaimGate | Require active claim. | Backend API | `worker_job_claims` | Active claim exists. | Missing/duplicate/conflict. | `backend_required` | Worker claim unavailable. | `workers.claim.blocked` | Transactional concurrency needed. |
| WorkerLeaseGate | Require valid lease. | Backend API | `worker_leases` | Lease active/not expired. | Expired/missing. | `backend_required` | Worker lease unavailable. | `workers.lease.blocked` | Add token hash later. |
| WorkerHeartbeatGate | Require timely heartbeat. | Backend API | heartbeats/claims | Heartbeat current. | Missing/stale. | `backend_required` | Worker heartbeat stale. | `workers.heartbeat.blocked` | Future backend-only write. |
| StaleClaimRecoveryGate | Govern stale recovery. | Backend API | claims/leases/jobs | Recovery safe and idempotent. | Not safe/requires transaction. | `backend_required` | Stale recovery unavailable. | `workers.stale_recovery.blocked` | No retry scheduling now. |
| RetryBudgetGate | Prevent unbounded retries. | Backend API | job attempts | Attempts within budget. | Budget exceeded. | `blocked` | Retry budget exhausted. | `workers.retry.blocked` | Needs job history. |
| IdempotencyGate | Prevent duplicate mutation. | Middleware/backend | `api_idempotency_keys` | Idempotency key valid. | Missing/conflict. | `blocked` | Retry with idempotency key. | `workers.idempotency.blocked` | Required on all mutation boundaries. |
| CancellationGate | Validate cancellation. | Backend API | job/claim/lease | Cancellation is allowed. | Already terminal/unsafe. | `blocked` | Cancellation cannot proceed. | `workers.cancel.blocked` | No mutation in Prompt 14. |
| ProviderExecutionBlockedGate | Block providers. | Backend API | none | Always blocks provider call. | Provider requested. | `blocked` | Provider calls are disabled. | `workers.provider.blocked` | Future Prompt 15. |
| RenderExecutionBlockedGate | Block render/export. | Backend API | none | Always blocks render/export. | Render requested. | `blocked` | Rendering is disabled. | `workers.render.blocked` | Future render worker milestone. |
| ToolExecutionBlockedGate | Block tools. | Backend API | none | Always blocks tool runtime. | Tool runtime requested. | `blocked` | Tool execution is disabled. | `workers.tool_execution.blocked` | Future activation only. |
| ProductionUnlockGate | Prevent beta/prod unlock. | Backend API | release approval | Explicit activation exists. | Missing approval. | `backend_required` | Production runtime is locked. | `workers.production_unlock.blocked` | Separate activation milestone. |
