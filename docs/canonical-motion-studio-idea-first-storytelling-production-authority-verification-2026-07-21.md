## Canonical Contract

The component binds all of the following into one content-addressed authority:

- exact workspace, project, named edit, and Storytelling production;
- approved or locked Prepared Script version and user-locked text state;
- ordered, unique, gap-free approved SceneDocument versions covering the exact Master Timing duration;
- approved or locked Voice Bible plus either verified uploaded narration identity or an explicit generated-speech requirement;
- source artifact approval snapshot;
- confirmed output frame and Master Timing authority;
- canonical Storytelling style component, selection, profile, and motion-language digests;
- one internal-production-cost ceiling that contains no customer price, credits, or service fee; and
- immutable proposal, repository-read, and authority hashes.

The server must re-read the exact component through
`CanonicalMotionStudioStorytellingProductionAuthorityReaderPort` before handoff preparation, inside the preparation lock, before publication, inside the publication mutation, before approval, inside the approval mutation, and when loading an approved snapshot. Missing, stale, substituted, cross-scope, or self-promoted authority fails closed.

This source version exposes only a controlled-local, source-verified, non-promotable reader contract. It does not expose a live production reader factory.
