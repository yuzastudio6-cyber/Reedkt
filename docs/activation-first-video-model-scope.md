# Activation First Video Model Scope

Phase 28 first real video testing is limited to speech/caption only.

Approved planning scope after Phase 26:

- `Systran/faster-whisper-tiny`
- faster-whisper with CTranslate2 runtime
- private staging artifacts only
- transcript/caption evidence for a controlled first real video test

Out of scope until later explicit phases:

- smart cut execution
- audio cleanup
- color processing
- masks/background removal
- enhancement/slow motion
- GPU-only model workflows
- provider calls
- production or external beta

Real user media testing remains blocked until Phase 28 explicitly approves the
controlled speech/caption test and model weights are actually available in the
approved runtime/storage path.
