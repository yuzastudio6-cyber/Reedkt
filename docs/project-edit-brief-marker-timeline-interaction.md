# Project Edit Brief Marker Timeline Interaction

RP-EDITBRIEF-06 makes the Edit Brief timeline interactive in mock/local mode.

Timeline behavior:
- Clicking empty timeline space moves the playhead only.
- Clicking Add Marker opens the drawer at the current playhead time.
- Point markers render as compact timeline pills.
- Range markers render wider timeline pills.
- Clicking a marker selects it and opens the editable drawer.
- Confirmed and warning-style marker states have distinct visual styling.

Not included:
- Marker dragging.
- Range edge dragging.
- Timeline zoom.
- Multi-select.
- Trim/cut tools.
- Real video playback from uploaded files.
