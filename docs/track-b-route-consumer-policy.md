# Track B Route Consumer Policy

Phase 44I allows consumer metadata for internal QA/planning and later worker orchestration only. It does not connect routes to live planner execution, frontend runtime calls, provider gateways, or production routing.

All consumers must respect approved capability ids, private artifact scopes, no frontend service-role secrets, no public output, no raw chat execution, and approved plan snapshots.

Sharp/libvips has a special boundary: Track B owns core runtime hardening, dependency policy, server/worker placement, and private artifact policy. Web search capture, AI Tools graphics, Track A visual pipeline, and media/data QA are consumers only. Track B does not claim those workflows or change Track A.
