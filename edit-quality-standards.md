# Edit Quality Standards

## Universal ReeditPro Standard

Every ReeditPro edit must meet a professional baseline.

Every edit must include:

- Clear source-order handling.
- Clean pacing.
- Understandable story structure.
- Clean cuts.
- Readable captions when captions are used.
- Safe caption placement.
- Nice color correction or grade.
- Clean audio level.
- Safe framing.
- No random effects.
- No random visuals.
- No random b-roll.
- No visuals covering important faces or products.
- Platform and ratio correctness.
- Approval before generation.

## Basic Standard

Basic is professional clean editing with lower compute. Basic is not low quality.

Basic must include:

- Professional clean edit.
- Dead-space removal.
- Basic pacing cleanup.
- Readable captions.
- Clean natural color correction.
- Basic shot matching.
- Voice cleanup and leveling.
- Tasteful simple transitions.
- Uploaded b-roll first.
- No unnecessary AI video generation.
- No Veo.
- No sloppy visuals.

Basic should avoid heavy generated assets, unnecessary retries, expensive Real Motion, random AI b-roll, and overcomplicated visual systems unless the user explicitly approves a revised plan and credit estimate.

## Pro Standard

Pro includes Basic plus:

- Stronger structure.
- Planned b-roll by segment.
- Better caption emphasis.
- Stronger Graphic Design / VisualExplain where useful.
- Stroke Motion where useful.
- Hailuo fallback allowed.
- Style-specific color grade.
- More SoundSync polish.
- More visual asset planning.
- No Veo.

Pro is the main production tier. It should feel more planned and polished than Basic, but not because Basic is low quality. Pro adds depth, fallback, and visual planning.

## Premium Standard

Premium includes Pro plus:

- Deeper story structure.
- More custom visual assets.
- Stronger character consistency.
- Scene-by-scene color grade.
- Secondary correction where useful.
- More retries.
- Stronger QA.
- Advanced SoundSync.
- Veo Lite final fallback only.
- Never default Veo.

Premium is the deepest planning tier. It can plan more fallback and rescue depth, but Veo remains fallback-only and must never be primary.

## Tier Comparison

Tiers change complexity, depth, fallback, and asset count.

Tiers do not change whether the output should be professional.

- Basic: professional fundamentals, lower compute, fewer generated assets, simpler fallback.
- Pro: stronger production planning, richer polish, Hailuo fallback, no Veo.
- Premium: deepest planning, stronger QA, more custom assets, more retries, Veo Lite final fallback only.

## QA Standard

Every edit plan should include QA checks for:

- User must-follow rules satisfied.
- Avoid rules not violated.
- Captions not covering face, product, animation panel, or important proof.
- Color grade matches selected style.
- B-roll supports meaning.
- Transitions match edit style.
- Sound is clean and not overpowering voice.
- Basic and Pro do not use Veo.
- Premium uses Veo only as final fallback.
- AI visuals stay inside frame panels.
- Generated backgrounds match frame panels.
- Source order changes were shown and approved.
- Approval happened before generation.

## Approval Standard

ReeditPro must plan first, estimate credits second, ask for approval third, and only then start editing, generation, rendering, or provider work.

This document does not authorize backend logic, provider calls, billing, rendering, exports, migrations, or mobile work.
