# Phase 44E Desktop Capability Privacy Policy

Phase 44E is designed to avoid fingerprinting and local inventory collection.

Blocked collection:

- persistent device identifiers
- hostnames and usernames
- MAC addresses and raw network interfaces
- exact CPU model strings
- exact GPU vendor/device IDs
- exact disk path lists
- directory scans, installed app scans, process lists, local file inventories
- environment variable dumps
- network speed tests and endpoint pings
- heavy CPU/GPU benchmarks
- telemetry upload or live profile upload
- local profile persistence by default

Allowed metadata is coarse, redacted, and session-only. Optional local collection is safe to skip and does not block Phase 44E.
