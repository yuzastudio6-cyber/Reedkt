# Phase 45C OpenTimelineIO Validation Policy

Phase 45C is Track A visual/video metadata validation only.

Allowed:

- Approved Phase 32 private source reference.
- Approved Phase 45A libass burn-in preview/report reference.
- Approved Phase 45B Remotion preview/report reference.
- Bounded OpenTimelineIO-compatible timeline JSON creation and validation.
- Private GCS metadata and QA artifacts.

Blocked:

- Final delivery.
- Arbitrary media.
- Media processing.
- Providers.
- Revideo.
- Track B tools.
- Production, external beta, paid production, and broad real media.
- Public URLs, public buckets, or signed URLs as source of truth.

Passing Phase 45C only makes Phase 45D ready for FFmpeg/FFprobe final render/export hardening.
