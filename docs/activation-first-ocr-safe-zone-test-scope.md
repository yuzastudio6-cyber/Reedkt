# First OCR Safe-Zone Test Scope

The first OCR safe-zone test is generated UI/text frame OCR only. The intended outputs are text region boxes, caption safe-zone metadata, and private QA artifacts that can later inform caption/render QA.

Real video OCR, arbitrary media, public output, provider calls, production, external beta, and broad real media remain blocked until later phases. Phase 37D is the earliest controlled real-video OCR safe-zone phase, and only after generated OCR runtime verification passes.
