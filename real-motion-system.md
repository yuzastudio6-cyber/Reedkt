# Real Motion System

## Definition

Real Motion is ReeditPro's realistic animated overlay system. It adds believable objects, products, places, proof, demonstrations, or symbolic visual moments inside the user's existing footage.

Real Motion is a visual signature system. It is premium and credit-heavy.

## Overlay-First Rule

Real Motion should stay integrated as an overlay inside the user's video. It is not default full-screen cutaway B-roll.

The user or speaker footage remains the base layer. Real Motion should add meaning on top of that base layer, not replace it by default.

## Face-Safe Placement

Real Motion must avoid blocking the speaker's face unless the edit plan intentionally explains why that placement is needed.

The planner should consider:

- Speaker face location.
- Important hand gestures.
- Product or object location.
- Existing captions.
- Graphic overlays.
- Safe zones for the target platform.

## Object Scale Based On Meaning

Object scale should match meaning:

- Big or important concept = stronger, larger, more dominant overlay.
- Small or detail concept = smaller, more precise overlay.
- Proof or demonstration = positioned close to the related spoken idea or visible object.
- Symbolic object = clear enough to understand but not so large that it distracts from the speaker.

## Object Behavior Types

Real Motion behavior can include:

- Appear/reveal.
- Follow or track a real object.
- Float beside the speaker.
- Slide in as proof.
- Assemble/disassemble.
- Transform from one state to another.
- Highlight a physical object or place.
- Point, circle, magnify, or compare.
- Animate symbolic evidence.
- Exit before the next idea begins.

## Blueprint Families

A blueprint family is a reusable planning pattern, not a repeated identical animation.

Examples:

- Product proof: product object, feature callout, comparison tag.
- Real estate/place: room highlight, floor-plan cue, location marker.
- Phone/app: screen card, tap cue, app feature overlay.
- Document/proof: document sheet, checkmark, evidence stamp.
- Book/page: opening page, highlighted line, note marker.
- Money/finance: bills, coins, calculator, chart cue.
- Package/unboxing: box reveal, label, contents cue.
- Before/after: split-state card, transform arrow, result badge.
- Symbolic object: key, ladder, shield, bridge, lightbulb.
- Environment/scene: weather, location marker, path, atmosphere cue.

## Same Idea, Not Exact Same Animation

The same topic can use the same blueprint family, but never the exact same animation every time.

Variation should consider:

- Transcript wording.
- Emotional tone.
- Object scale.
- Entry and exit timing.
- Motion path.
- Camera framing.
- Platform aspect ratio.
- Existing captions and overlays.
- Credit budget.

## Credit Cost

Real Motion is premium and credit-heavy because it can require:

- Visual footage analysis.
- Object selection.
- Placement planning.
- Face-safe checks.
- Motion generation.
- Composite/rendering work.
- Review and regeneration.

Real Motion should be estimated before generation and deducted only after approval.

## Planning Steps

1. Identify the spoken concept or visual proof need.
2. Check whether Real Motion improves the segment.
3. Confirm the base video remains primary.
4. Identify safe placement.
5. Choose object scale based on meaning.
6. Select a blueprint family.
7. Plan timing against speech and StoryTiming.
8. Estimate credits.
9. Show the Real Motion plan to the user.
10. Generate only after approval.

## Category Examples

### Product/Object

Speaker describes a product feature. Real Motion adds a product-like overlay or feature callout near the product area without covering the speaker.

### Real Estate/Place

Speaker tours a room. Real Motion adds a subtle room label, location marker, or floor-plan cue inside the footage.

### Phone/App

Speaker discusses an app. Real Motion adds a realistic phone screen overlay or tap cue beside the speaker.

### Document/Proof

Speaker mentions evidence. Real Motion adds a document, checkmark, proof stamp, or highlighted paper overlay.

### Book/Page

Speaker mentions a book, lesson, or chapter. Real Motion adds a page turn, highlighted line, or margin note overlay.

### Money/Finance

Speaker explains savings, revenue, or cost. Real Motion adds bills, coins, calculator, or chart objects scaled to the importance of the point.

### Package/Unboxing

Speaker shows or mentions a package. Real Motion adds a box reveal, label animation, or contents cue.

### Before/After

Speaker describes transformation. Real Motion adds a realistic transform marker, result badge, or split-state object.

### Symbolic Object

Speaker uses a metaphor. Real Motion adds a symbolic key, bridge, ladder, shield, or light cue inside the footage.

### Environment/Scene

Speaker references a place, weather, or situation. Real Motion adds environmental cues that support the scene without becoming a full cutaway.
