# Qwen Timeout Calibration Policy

Primary target: `qwen3.7-plus`.

Escalation target: `qwen3.7-max`, evidence-only unless a later target decision approves replacement.

Known unavailable alias: `qwen-max`; it is not retested by this phase.

Streaming is allowed only as a calibration mode for synthetic schema evidence. Raw provider responses, secret payloads, raw prompts, public artifacts, and signed URLs are not stored.
