# AI Graphics Controlled No-Op Worker Gate Observability Audit Policy

Future controlled no-op validation may record static observability and audit
summaries for:

- source PR chain and run IDs,
- 13-tool matrix coverage,
- scoped pass claim acceptance,
- generic claim rejection,
- job claim, lease, and queue placeholder checks,
- no-execution proof,
- fail-closed status,
- cleanup status.

Any local evidence must remain ignored under `.local-artifacts/` and must not be
committed.
