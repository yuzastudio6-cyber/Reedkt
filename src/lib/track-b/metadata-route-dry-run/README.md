# Track B Metadata Route Dry-Run

Pure TypeScript validators and metadata-only dry-run helpers for Phase 44O.

This library validates the Phase 44N DuckDB metadata route approval packet, plan snapshot, artifact scope, secret guard, route metadata, cost guard, sidecar validation response, and fail-closed fixtures. It does not import server code, DuckDB, Polars, workers, subprocess APIs, media/tool runtimes, provider code, secrets, or Track A.
