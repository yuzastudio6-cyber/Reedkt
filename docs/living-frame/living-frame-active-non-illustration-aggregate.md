# Living Frame Active Non-Illustration Aggregate

## Purpose

`living-frame-active-non-illustration-aggregate-v1` is the source-only
replacement for using the historical Living Frame private aggregate as an
active completion signal.

The historical aggregate contains illustrated-character animation, keyposes,
interpolation, living-subject rigs, Blender character fixtures, and mechanical
rigging research that the owner has paused. Those records remain research or
negative evidence. They cannot make the amended Living Frame scope ready.

This contract does not execute the new aggregate. It defines its exact active
case manifest so a later runtime runner cannot silently inherit the historical
case list.

## Exact Active Cases

The manifest contains one ordered case for every active scope in
`living-frame-owner-scope-amendment-v1`:

1. Living A-Roll compositing;
2. static illustration without character animation;
3. non-character Living Still selective motion;
4. Living Archive;
5. Living Diagram;
6. non-character Hybrid Expansion;
7. maps, routes, and data graphics;
8. attention, Focus Handoff, and Semantic Scale;
9. camera, depth, occlusion, and masks;
10. environmental, editorial, and simple rigid-support motion;
11. SoundSync, StoryTiming, and Caption Direction coordination; and
12. Remotion composition, visual QA, repair, and canonical private review.

The case order must exactly match the owner amendment. Reordering, omitting,
duplicating, or substituting a case fails compilation.

## Evidence Packets

Every case binds one fixed, byte-free evidence-packet identity. The caller may
provide only the packet digest and the exact server-defined packet ID/version.
Packets must state that:

- canonical reread is still required;
- no runtime evidence is included; and
- no paused evidence is included.

Each case also records exact dependency IDs for its canonical owner surfaces,
versioned contracts, and recorded fixtures that still require reinspection.
The future canonical runner must reread the corresponding immutable evidence;
the manifest does not claim that an owner surface or historical fixture has
already been admitted. It does not copy source media, map coordinates, data
values, document excerpts, claims, prompts, paths, URLs, credentials,
commands, or environment data.

## Paused Routes

All seven owner-paused scopes are recorded as rejected:

- illustrated-character animation;
- living or organic subject animation;
- complete-character keypose generation;
- character pose interpolation;
- character frame-cadence smoothing;
- living or organic subject rigging; and
- mechanical-object rigging.

The contract imports neither the historical aggregate nor its case count. No
historical character, keypose, interpolation, Blender/OpenToonz character-rig,
or mechanical-rig evidence may satisfy an active case.

Static illustrations remain permitted only as unanimated visual elements
unless a future explicit owner specification reopens animation.

## Visual Review

Every active case requires deterministic QA, complete-time postrender AI visual
inspection, separate verified audio evidence, Head QA recommendation, and
canonical private review. A failed case must create an N+1 artifact and repeat
technical QA, visual inspection, audio verification, Head QA, reconciliation,
and private review. Technical metrics, pixel deltas, successful rendering,
caller booleans, or historical review claims cannot approve professional
quality.

The later runtime aggregate must bind each rendered artifact to:

- deterministic media QA;
- complete-time Qwen visual evidence;
- separate verified audio evidence when applicable;
- Kimi-primary or allowed Terra-fallback Head QA recommendation;
- N+1 repair and repeated inspection when required; and
- canonical private-review assembly.

## Ownership

The manifest does not own approved snapshots, selected scenes, MasterTiming,
SoundSync, Caption Direction, maps, data visualization, documentary fact
safety, layout, depth, masks, the work graph, asset manifest, Remotion,
provider routing, artifacts, QA approval, private review, cost, billing,
delivery, or production.

All those authorities remain with their existing canonical owners.

## Current Status

The 12-case source manifest and fail-closed verifier are implemented. Runtime
execution, immutable evidence reread, work admission, asset creation,
postrender inspection, Head QA, repair, reconciliation, and private review are
still pending. `activePrivateInternalReady`, runtime, provider, dispatch,
billing, public-delivery, and production authority remain false.
