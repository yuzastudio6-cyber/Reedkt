# Track All tool gap report

## Blocking external gaps

- Human authorization for the gated SAM 3.1 checkpoint and its terms.
- Exact checkpoint bytes/hash and private ingest.
- Strict public-source/checkpoint compatibility while official issue #526 is open.
- Immutable A100 and optional L4 images plus real private canaries.
- Production durable artifact store, worker lease, rate authority, monitoring, privacy/security approval, and release approval.

## Repository gaps closed by this Goal

- One top-level Track All plugin, manifest, schemas, work graph, bindings, QA, qualification, and retirement authority.
- Track Graph V2 with V1 compatibility owned in shared code.
- Forward-only SAM masklet operation and strict session plan.
- Deterministic camera/planar geometry, privacy/focus/reframe fixtures, and model-neutral handoffs.

## Deliberately deferred candidates

PaddleOCR, MediaPipe, Kornia production use, OpenColorIO/OpenImageIO treatments, and browser capture require route-specific qualification. BiRefNet, rembg, transparent-background, and SAM2 are not eligible Track All fallbacks.
