# Future Backend Service Map

This map defines future backend services and their boundaries. It is documentation-only and does not create service-role handlers, routes, deployments, or runtime execution.

| Service | Responsibility | Allowed inputs | Allowed writes | Forbidden behavior | Main tables | Route group | Future worker dependency |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `AuthBootstrapService` | Ensure authenticated users have safe profile/workspace bootstrap. | Auth user, workspace request, idempotency key. | User profile, workspace/member bootstrap, audit events. | Bypass RLS without audit; expose service-role data. | `user_profiles`, `workspaces`, `workspace_members`, audit events. | `auth` | None. |
| `WorkspaceAccessService` | Enforce workspace membership and role checks. | Auth user, workspace ID, action. | Audit/access events only. | Grant implicit access or leak cross-workspace data. | `workspaces`, `workspace_members`. | `auth`, `projects` | None. |
| `ProjectService` | Create/read/update project metadata within workspace policy. | Workspace ID, user ID, project fields, idempotency key. | `projects`, project audit events. | Mutate projects outside workspace role or bypass approvals. | `projects`, `chat_sessions`. | `projects` | None. |
| `ChatPersistenceService` | Persist chat messages, attachments, and inline action records. | Chat message payload, attachment refs, project ID. | `chat_messages`, `chat_attachments`, `inline_chat_cards`, `chat_actions`. | Treat raw chat as worker instruction or execution contract. | Chat/project tables. | `chat` | May feed planning workers later. |
| `UploadIntentService` | Create and validate upload intents. | Project ID, file metadata, source order, idempotency key. | `upload_intents`, upload audit events. | Create canonical media without validation. | `upload_intents`, `projects`. | `storage`, `media` | Media probe worker consumes completed uploads later. |
| `SignedUrlService` | Issue temporary signed upload/download URLs. | Upload intent or storage object ID, user/project context. | `signed_url_events`. | Persist signed URLs as source of truth or expose private paths without auth. | `signed_url_events`, `storage_object_records`. | `storage` | Workers should use canonical paths, not signed URLs. |
| `StorageObjectService` | Validate and create canonical private storage object records. | Upload completion, bucket/path, metadata, project context. | `storage_object_records`, `media_assets`. | Accept frontend-invented canonical records without backend validation. | `storage_object_records`, `media_assets`. | `storage`, `media` | All media/render/provider workers depend on storage refs. |
| `MediaReadinessService` | Track media probe/readiness status. | Storage object ID, probe result, worker job ID. | Media readiness/probe fields, job events, audit events. | Mark unprobed or unsupported media ready. | `media_assets`, readiness records, `job_events`. | `media`, `workers` | `media_probe_worker`. |
| `IntentPlanningService` | Convert chat/source facts into structured intent and plan records. | Chat, source order, media facts, user instructions. | Intent analysis, edit plans, segment plans, planning audit events. | Plan from raw chat alone when required media facts are missing. | `intent_analyses`, `edit_plans`, planning tables. | `planning` | Future transcript/visual/audio workers. |
| `ApprovedSnapshotService` | Create immutable approved execution snapshots. | Approved plan, approved estimate, reservation if required, timing/frame context. | `approved_plan_snapshots`, idempotency/audit records. | Mutate snapshot payload after approval or create from stale plan. | `approved_plan_snapshots`, `api_idempotency_keys`. | `planning`, `approval` | All execution workers. |
| `CreditEstimateService` | Calculate and persist credit estimates. | Plan, asset/render/tool/provider scope, tier, user/workspace. | `credit_estimates`, line items. | Imply subscription is unlimited AI editing. | `credit_estimates`, estimate line items. | `credits` | Provider/render/tool lanes may require estimates. |
| `CreditReservationService` | Reserve/release credits for approved work. | Approved estimate, wallet, idempotency key, operation scope. | `credit_reservations`, ledger/audit records. | Reserve without approved estimate or snapshot where required. | `credit_reservations`, `credit_ledger_entries`. | `credits` | Required for credit-bearing workers. |
| `CreditLedgerService` | Append-only spend/refund/release ledger mutation. | Reservation ID, job/result status, refund reason. | `credit_ledger_entries`, refunds, wallet balance views. | Edit ledger rows in place or spend without reservation. | Credit wallet/ledger/refund tables. | `credits` | Provider/render/export jobs report outcomes. |
| `JobOrchestrationService` | Create jobs, dependencies, batches, and dispatch intent. | Approved snapshot, operation request, idempotency key. | `jobs`, `job_batches`, `job_dependencies`, `job_events`. | Create jobs without required gates or raw-chat jobs. | Job tables and events. | `jobs` | All worker lanes. |
| `WorkerClaimService` | Claim, renew, release, complete, fail, or cancel work. | Job ID, worker identity, runtime profile, idempotency key. | `worker_job_claims`, `worker_leases`, claim attempts, job events. | Allow duplicate active claims for one job. | Claim/lease/job tables. | `workers` | All worker lanes. |
| `WorkerHeartbeatService` | Track worker liveness and stale recovery. | Claim ID, heartbeat payload, worker runtime ID. | Heartbeat/lease records, recovery events. | Log secrets or revive stale jobs without idempotency. | Worker lease/claim/event tables. | `workers` | All long-running worker lanes. |
| `ProviderGatewayService` | Normalize and gate provider requests. | Approved snapshot, provider route, prompt brief, reservation, storage refs. | `provider_request_attempts`, provider events, generated asset records. | Expose secrets, call providers before gates, or ignore tier/model policy. | Provider attempt/webhook/generation tables. | `providers` | `provider_asset_worker`, SFX/music workers. |
| `ToolCallIntentService` | Record and validate tool call intent before execution. | Approved snapshot, tool strategy, operation scope. | Tool call intent records, audit events. | Execute tools directly or from raw chat. | Future tool intent tables, `tool_runtime_checks`. | `tools` | `tool_execution_worker` and specialized tool lanes. |
| `ToolReadinessService` | Store tool runtime readiness and compliance state. | Worker runtime profile, safe version/import check output, compliance status. | `tool_runtime_checks`, readiness events. | Treat missing license approval as ready. | `tool_runtime_checks`, tool registry references. | `tools`, `workers` | Tool and render/media lanes. |
| `RenderJobService` | Create and gate preview/final render jobs. | Approved snapshot, render scope, asset refs, reservation. | `render_jobs`, `render_job_inputs`, job events. | Render without snapshot, timing, assets, or QA gates. | Render/job/storage tables. | `render` | `remotion_render_worker`, `ffmpeg_postprocess_worker`. |
| `RenderManifestService` | Build renderer manifests from approved records. | Approved snapshot, timing plan, asset manifest, frame context. | Render manifest records/artifacts. | Change frame/aspect/timing after approval. | Render manifest/timing/render tables. | `render` | Render workers. |
| `QAReportService` | Persist QA reports and blocking issues. | Worker QA output, render/provider/tool asset refs. | `qa_reports`, `qa_report_items`, job events. | Allow final export with blocking QA. | QA/job/render/export tables. | `qa` | `qa_worker`, render/export workers. |
| `RevisionService` | Record preview review and material revision requests. | User review, QA issue, plan change request. | `preview_reviews`, `review_comments`, `revision_requests`. | Apply material changes without new plan/estimate/snapshot approval. | Review/revision/plan tables. | `revisions` | Planning/render/QA lanes may trigger revisions. |
| `ExportService` | Gate and create final export records. | Approved snapshot, final render, QA pass, storage target, reservation. | `exports`, `export_variants`, storage records, audit events. | Export with placeholders, blocking QA, or missing approved snapshot. | Export/render/storage/QA tables. | `exports` | `export_worker`, render workers. |
| `AuditEventService` | Append sanitized audit events for privileged actions. | Event name, actor, project/workspace, sanitized metadata. | Audit/event tables. | Store secrets, signed URLs, raw provider payloads, or private credentials. | `event_log`, audit tables. | `audit` | All services and workers emit events. |
