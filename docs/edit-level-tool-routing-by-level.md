# Edit Level Tool Routing By Level

RP-EDITLEVEL-05 makes Edit Level selection meaningful by resolving a mock/local capability package for each level.

| Capability area | Normal | Premium | Ultra Premium |
| --- | --- | --- | --- |
| Qwen 3.7 | Standard reasoning profile; deterministic fallback. | Deep reasoning profile for story, marker, style, and source-summary decisions. | Multi-pass reasoning profile for studio-level direction and QA explanation. |
| Qwen2.5-VL | Targeted and optional when visual ambiguity matters. | Key moments and marker windows. | Scene-level/deep visual policy. |
| Transcript | Optional or targeted. | Recommended when speech exists. | Required when speech exists. |
| Media extraction | Basic metadata only; worker future-gated. | Metadata plus key moments/keyframe plan. | Deeper keyframe/waveform plan. |
| Audio/SoundSync | Basic voice-first audio guidance. | Music, SFX, ducking, and SoundSync recommendations. | Sound design planning and stricter voice-first audio direction. |
| Graphics | Basic captions and clean text. | Styled captions/cards. | Motion graphics and layout direction. |
| Edit Brief | Optional. | Recommended. | Strongly recommended. |
| Preference DNA | Safe style hints. | Strong DNA application. | Deep DNA application. |
| DeepSeek | Future tool-code only, not user reasoning. | Future tool-code only, not user reasoning. | Future Remotion/tool-code only, not user reasoning. |
| Render/Credits | Future-gated and estimate-only. | Future-gated and estimate-only. | Future-gated and estimate-only with highest future budget metadata. |

All levels remain professional. Higher levels increase depth, polish, QA strictness, and future budget, not baseline quality.
