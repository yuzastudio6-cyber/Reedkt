## Rules

- Commit only redacted evidence.
- Do not commit secrets, keys, passwords, full connection strings, signed URLs, private media URLs, raw row data, or real user data.
- Do not include executable SQL, Supabase lifecycle commands, migration commands, deployment commands, provider calls, worker execution, rendering commands, storage transfer commands, credit mutation commands, Stripe commands, or telemetry commands.
- Do not claim staging approval, production readiness, beta unlock, Supabase mutation, or audit completion from this directory alone.
