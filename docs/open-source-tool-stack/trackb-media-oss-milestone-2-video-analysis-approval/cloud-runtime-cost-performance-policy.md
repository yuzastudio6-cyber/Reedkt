# Cloud Runtime Cost And Performance Policy

Milestone 2 remains CPU-first and low/medium cost. Future small proofs should target a CPU Cloud Run Job or CPU worker with 2-4 vCPU and 4-8 GiB RAM. Heavier internal validation may review 4-8 vCPU and 8-16 GiB RAM.

GPU is not approved. GPU escalation requires separate approval and measured CPU latency/memory evidence.

No product runtime, beta, or production unlock is approved.
