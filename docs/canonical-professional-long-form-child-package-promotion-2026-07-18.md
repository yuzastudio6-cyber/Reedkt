## Atomic Authority Boundary

The package and placement records are content-addressed immutable preparation
blobs. The single checksum-protected queue aggregate is the promotion commit.
Its definition hash binds the exact package, placement, bridge, seed, child
manifest, snapshot, controller, and policy identities. Prepared blobs that are
not referenced by a successfully committed queue grant no lease, dispatch, or
execution authority.

Concurrent promotion requests converge on exactly one `created` result and one
`exact_replay` result. Restart replay reopens the same aggregate without adding
an event or delivery attempt. A checksum-corrupted queue fails closed; after the
exact original bytes are restored, the same request replays without creating a
second queue.
