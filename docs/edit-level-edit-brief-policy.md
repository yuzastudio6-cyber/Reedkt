# Edit Level Edit Brief Policy

The Edit Brief is an optional timeline instruction layer inside an Edit Chat. It can guide markers, must-follow moments, avoid moments, and segment-level creative intent.

## Level Policy

| Level | Policy | Planning behavior |
| --- | --- | --- |
| Normal | Edit Brief optional. | Use it when present, but do not require it for a clean professional edit. |
| Premium | Edit Brief recommended. | Prioritize markers and instructions when present; recommend adding a brief for stronger control. |
| Ultra Premium | Edit Brief strongly recommended. | Encourage a brief for launch, brand, ad, cinematic, or complex work; missing brief creates a planning warning, not a generic blocker. |

## Conflict Handling

Future planning should detect conflicts between Edit Brief markers, chat instructions, source order, safety rules, tier/model policy, and credit budget. Explicit user instructions still have priority unless constrained by safety, approval gates, frame rules, model policy, or platform rules.

## Boundary

RP-EDITLEVEL-01 does not add Edit Brief UI behavior, marker execution, runtime types, repositories, routes, or worker logic. It only documents the future policy.
