# Phase 36K Demucs Weight Artifact Policy

Phase 36K must not download, cache, stage, hash, or execute Demucs weights.

Future Phase 36L requirements:
- human/legal approval for one exact candidate
- exact artifact source URL
- immutable version or revision
- SHA-256 manifest
- private GCS staging path
- no public artifacts
- no signed URLs as source of truth
- no committed weights
- no runtime auto-download
- private generated fixture plan before controlled or broad media

Until those conditions are met, Demucs model artifacts remain blocked.
