## Decision

for the eight effective representative source candidates.

topic-matched Earth Day B-roll as 1920×1080 MP4 files. V2 selects those official
MP4 variants, forbids WebM substitution, and requires no conversion lane.

JPEG, PNG, and SVG records explicitly require a canonical uploaded-visual
source-reader extension. The EIA JSON record explicitly requires the canonical
structured-data snapshot owner. V2 does not create either missing owner.
