# Project Edit Brief Marker Read-Only Panel

RP-EDITBRIEF-05 shows selected marker details without mutation.

## Displayed Fields

- Marker title, type, status, priority, QA/conflict status, and time/range.
- User note and structured intent summary.
- Metadata-only attachment chips.
- Marker Chat message count.
- Planner hints and do-not-copy notes.
- Boundary copy: marker editing, attachments, and Marker Chat arrive in future Edit Brief milestones.

## Not Included

No create, edit, delete, confirm, archive, attach, upload, Marker Chat composer, conflict resolution, planner application, provider/model call, worker, render, credits, Supabase command, migration, staging, commit, or cleanup.
