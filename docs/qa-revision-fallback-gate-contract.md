# QA, Revision, And Fallback Gate Contract

Future QA/revision/fallback workers must enforce these gates before writing records or starting downstream work.

| Gate | Purpose | Checked by | Required records | Pass condition | Fail condition | Failure status | User-facing message style | Audit event | Future notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| AuthGate | Require an authenticated user. | Backend API | Auth session | User is authenticated. | Missing/invalid auth. | unauthorized | Ask user to sign in. | `qa.auth_failed` | All routes require auth. |
| WorkspaceGate | Prevent cross-workspace access. | Backend API | `projects`, `workspace_members` | Project belongs to workspace. | Workspace mismatch. | blocked | Say project is not accessible. | `qa.workspace_blocked` | Use Prompt 3 project access service. |
| ProjectAccessGate | Require project membership. | Backend API | `workspace_members` | User is a workspace member. | No membership. | blocked | Say project is not accessible. | `qa.project_denied` | Service-role read must not leak data. |
| ApprovedSnapshotGate | Tie QA/revision to approved plan. | QA service | `approved_plan_snapshots` | Snapshot exists and is approved. | Missing/unapproved snapshot. | backend_required | Say approved plan is required. | `qa.snapshot_required` | No raw chat execution. |
| PreviewRenderGate | Require preview/render reference for review. | QA service | `renders`, `render_jobs` | Preview/render exists and is project-scoped. | Missing render reference. | backend_required | Say preview is not ready. | `qa.preview_required` | No render polling in Prompt 11. |
| RenderReadinessGate | Ensure render can be reviewed. | Render/QA service | `renders`, render readiness summaries | Render status is reviewable. | Render is missing/failed/blocked. | blocked | Say preview must be ready first. | `qa.render_not_ready` | Prompt 10 remains fail-closed. |
| QAReportGate | Require QA record availability. | QA service | `qa_reports` | QA report exists or creation boundary is validated. | Missing QA runtime. | backend_required | Say QA is not available yet. | `qa.report_required` | Creation remains backend-required. |
| QABlockerGate | Block export on QA failures. | QA/export service | `qa_check_results` | No blocking QA checks. | Blocking check exists. | blocked | Say QA issue must be resolved. | `qa.blocked` | Prompt 11 only reports blockers. |
| RequiredAssetGate | Prevent output with missing assets. | QA/render service | Asset/storage summaries | Required assets present. | Missing required asset. | blocked | Say asset is missing. | `qa.asset_missing` | Future asset manifest dependency. |
| MediaReadinessGate | Require media/source readiness. | QA/media service | `media_assets`, `storage_object_records` | Media is ready for QA/review. | Media readiness missing. | backend_required | Say media readiness is needed. | `qa.media_required` | No media inspection in Prompt 11. |
| TimingValidationGate | Protect timing correctness. | QA/timing service | Timing validation records | Timing validation passes. | Missing/failing timing validation. | backend_required | Say timing needs validation. | `qa.timing_required` | Frame-accurate future worker. |
| CaptionReadabilityGate | Protect captions and safe zones. | QA service | Caption/timing QA records | No readability blocker. | Caption unreadable/colliding. | blocked | Say captions need adjustment. | `qa.caption_blocked` | Future caption QA. |
| SafeZoneGate | Prevent visual/caption collisions. | QA service | QA check records | No safe-zone blocker. | Face/product/text collision. | blocked | Say layout needs adjustment. | `qa.safe_zone_blocked` | Future visual QA. |
| CreditEstimateGate | Require estimate for material revision. | Credit/QA service | `credit_estimates` | Estimate exists if needed. | Estimate missing. | backend_required | Say revision needs estimate. | `revision.estimate_required` | No estimate mutation in Prompt 11. |
| CreditReservationGate | Require reservation before paid retry. | Credit/QA service | `credit_reservations` | Reservation active if credits apply. | Missing/inactive reservation. | backend_required | Say credits must be reserved. | `revision.reservation_required` | Prompt 6 remains fail-closed. |
| RevisionScopeGate | Classify change scope. | Revision service | `revision_requests` | Scope is safe and project-scoped. | Unsafe/cross-project scope. | blocked | Say request cannot proceed. | `revision.scope_blocked` | Material changes reset approval. |
| RevisionApprovalGate | Require new approval when material. | Revision service | `approval_records` | Required approval exists. | Approval missing. | backend_required | Say approval is required. | `revision.approval_required` | No approval mutation. |
| FallbackAllowedGate | Use only approved fallback paths. | Fallback service | Approved snapshot fallback policy | Fallback is allowed. | Fallback not approved. | blocked | Say fallback needs approval. | `fallback.not_allowed` | Workers must not improvise. |
| RetryBudgetGate | Prevent uncontrolled retries. | Fallback/credit service | Credit/retry policy | Retry budget available. | Retry budget exceeded. | blocked | Say retry needs review. | `fallback.retry_blocked` | Future cost controls. |
| UserReviewGate | Require user review for risky fixes. | Revision service | Review/revision records | User review not required or completed. | User review pending. | blocked | Ask user to review. | `revision.user_review_required` | Meaning/privacy risks require review. |
| ExportBlockerGate | Prevent final export with unresolved blockers. | Export/QA service | `qa_check_results`, `revision_requests` | No blocking QA/revision items. | Blocking item exists. | blocked | Say export is blocked. | `export.qa_blocked` | Prompt 10 export remains fail-closed. |
| ProviderExecutionBlockedGate | Keep providers disabled. | QA service | None | Provider execution not requested. | Provider call attempted. | backend_required | Say provider execution is not enabled. | `qa.provider_blocked` | Future provider gateway only. |
| RenderExecutionBlockedGate | Keep rendering disabled. | QA service | None | Render execution not requested. | Render/export attempted. | backend_required | Say rendering is not enabled. | `qa.render_execution_blocked` | Prompt 10 boundary only. |
| ToolExecutionBlockedGate | Keep tool execution disabled. | QA service | None | Tool execution not requested. | Tool call attempted. | backend_required | Say tool execution is not enabled. | `qa.tool_blocked` | Prompt 12 starts tool-call foundation. |
| WorkerExecutionBlockedGate | Keep workers disabled. | QA service | None | Worker execution not requested. | Worker dispatch attempted. | backend_required | Say worker execution is not enabled. | `qa.worker_blocked` | Future worker milestone. |
