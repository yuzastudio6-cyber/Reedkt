# Phase 36K Demucs Model Provenance Report

Inventoried candidates include `htdemucs`, `htdemucs_ft`, `htdemucs_6s`, `hdemucs_mmi`, `mdx`, `mdx_extra`, `mdx_q`, `mdx_extra_q`, and Torchaudio HDemucs bundles.

None are approved for download or runtime in Phase 36K. The default/high-quality candidates reference MUSDB-HQ plus extra or internal songs, and the lower-risk MUSDB-only candidates still require legal review because MUSDB/MUSDB-HQ carries academic, noncommercial, sharealike, and source-track licensing caveats.

Phase 36L may start only after a human/legal reviewer approves one exact model candidate, exact artifact URL, immutable checksum, and private staging policy.
