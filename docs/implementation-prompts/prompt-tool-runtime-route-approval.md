# Prompt: Tool Runtime Route Approval Packet

Create a future Track B approval packet for one lowest-risk runtime route after Phase 44O.

The packet must:

- select exactly one tool and capability
- load Phase 44O evidence
- define an approved plan snapshot and private artifact scope
- require explicit human approval and current-shell confirmations
- block secrets, broad media, public output, providers, VLM, Demucs, raw chat execution, production, beta, and Track A
- avoid executing the runtime in the approval packet itself

The execution phase must be separate from the approval packet.
