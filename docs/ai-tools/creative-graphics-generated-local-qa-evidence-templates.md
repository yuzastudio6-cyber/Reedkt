# Creative Graphics Generated/Local QA Evidence Templates

Status: `generated_local_fixture_candidate_prepared`

The templates below describe evidence that future generated/local fixture execution must collect. GD-3 does not generate, inspect, render, upload, or store artifacts.

| Template | Required evidence fields |
| --- | --- |
| Static visual asset | Fixture candidate ID, expected artifact type, dimensions, aspect ratio, safe-zone check, typography/readability, brand/style, manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Transparent overlay | Fixture candidate ID, expected artifact type, dimensions, alpha/transparency check, safe-zone check, timing if temporal, manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Motion overlay | Fixture candidate ID, expected artifact type, dimensions, fps, duration frames, timing alignment, readability, safe-zone check, manifest completeness, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Chart/dataviz | Fixture candidate ID, expected artifact type, dimensions, aspect ratio, data correctness from synthetic dataset, label readability, manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Diagram/Graphviz | Fixture candidate ID, expected artifact type, dimensions, graph correctness, node/edge label readability, safe-zone check, manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Social card | Fixture candidate ID, expected artifact type, dimensions, aspect ratio, typography/readability, brand/style, public artifact blocked, manifest completeness, checksum/provenance placeholder, blocked-use compliance, pass/fail result placeholder |
| Rasterization | Fixture candidate ID, expected artifact type, source vector placeholder, target raster placeholder, dimensions, alpha check if required, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| 3D/canvas scene manifest | Fixture candidate ID, expected artifact type, dimensions, aspect ratio, timing if temporal, safe-zone check, scene/canvas manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Lottie overlay | Fixture candidate ID, expected artifact type, timing, alpha/transparency check, caption collision risk, manifest completeness, checksum/provenance placeholder, Track A compatibility, blocked-use compliance, pass/fail result placeholder |
| Remotion preview manifest | Fixture candidate ID, expected artifact type, dimensions, fps, duration frames, layer timing, safe-zone check, manifest completeness, checksum/provenance placeholder, Track A compatibility, render/export blocked, pass/fail result placeholder |

Universal blocked-use checks: raw prompt worker execution, signed URL source-of-truth, public artifact, final delivery without Track A validation, provider fallback without approval, and production/beta unlock.
