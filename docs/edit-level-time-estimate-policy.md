# Edit Level Time Estimate Policy

RP-EDITLEVEL-09 defines deterministic mock/local time ranges for visible beta planning copy.

| Level | Placeholder range | Meaning |
| --- | --- | --- |
| Normal | 20-45 minutes | Clean professional edit with targeted analysis and baseline QA. |
| Premium | 45-90 minutes | Enhanced creative edit with deeper story, source, audio, and QA policy. |
| Ultra Premium | 90-180 minutes | Studio-level treatment with scene-level context, strict QA, and deeper future iteration budget. |

These ranges are estimate-only. They do not create a plan, run a real planner, start progress, reserve workers, process media, call providers, call Qwen, or create a render/export job.

Time values remain mock UX forecasts until real approved-plan timing, worker readiness, source duration, tool execution, render/export, and credit gate services exist.
