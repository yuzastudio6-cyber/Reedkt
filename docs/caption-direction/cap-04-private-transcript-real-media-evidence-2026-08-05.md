internal MP4 and produced real segment and ASR-native word timing artifacts.
Direct inspection of every transcript segment and the first, middle, and last

runtime output contains a product/brand-name misrecognition, several
semantically garbled phrases, and a high density of low-confidence words. It
therefore cannot create the final phrase-lineage projection or qualify final

## Repairs made

- The inspection contract now has explicit accepted and rejected
  dispositions.
- Accepted evidence requires an exact independent audio-truth review ref,
  complete transcript inspection, verified proper names/claim-sensitive terms,
  and no declared defect.
- Rejected evidence requires at least one closed defect code and permanently
  records `finalPhraseProjectionAllowed: false`.
- The phrase-projection builder now consumes the full inspection receipt and
  refuses rejected or cross-transcript evidence.
- Runtime qualification refuses mismatched low-confidence counts/ratios and
  any rejected receipt.
- Adversarial checks prove that recomputed-digest authority overclaims,
  duplicate defects, a forged acceptance without independent review, crossed
  transcript lineage, and phrase projection from rejected text all fail
  closed.
- The model bootstrap now removes only downloader-owned `.cache` metadata and
  verifies exactly four allowlisted model files before hashing the reviewed
  runtime directory.
