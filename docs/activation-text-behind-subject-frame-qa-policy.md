# Phase 33E Text-Behind-Subject Frame QA Policy

QA must emit:

- `mask_edge_quality`
- `mask_subject_coverage`
- `render_asset_integrity`
- `text_readability`
- `text_safe_zone`
- `text_behind_subject_composition`
- `final_delivery`

`final_delivery` is not applicable because Phase 33E is a private single-frame
preview, not a video export. Safe-zone review is warning-only unless a later
phase adds stronger face/OCR analysis.
