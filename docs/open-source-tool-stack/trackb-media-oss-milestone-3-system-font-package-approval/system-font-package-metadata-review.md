# System Font Package Metadata Review

`fonts-noto-cjk` is approved as the future primary package for the next bounded execution gate. Debian metadata describes it as CJK regular and bold Noto coverage for Traditional Chinese, Simplified Chinese, Japanese, and Korean families.

`fonts-noto-cjk-extra` remains secondary/fallback. Debian metadata describes it as all-weight CJK coverage, with larger package and installed size, and it depends on `fonts-noto-cjk`.

No package was installed in this phase. No Dockerfile, requirements, lockfile, or runtime configuration was changed.
