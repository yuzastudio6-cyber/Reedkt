# Edit Level Source Understanding By Level

| Level | Depth | Summary |
| --- | --- | --- |
| Normal | `metadata_and_targeted_context` | Clean professional source pass: video metadata, export fit, and targeted context only when needed. |
| Premium | `key_moments_and_marker_windows` | Deeper source understanding: key visual moments, transcript-aware planning, audio/music/SFX guidance, styled captions/cards, and stronger context for markers. |
| Ultra Premium | `scene_level_deep_context` | Studio-level source understanding: scene-level visual analysis, transcript and audio timing, graphic/layout observations, advanced B-roll strategy, and strict context-aware QA. |

All levels remain professional. Higher levels increase depth, polish, analysis, QA strictness, and future budget; they do not control basic correctness.

Unavailable tools degrade explicitly. Normal uses metadata/deterministic summaries, Premium uses key-moment mock fallback, and Ultra Premium degrades to Premium-safe context with degraded capability copy.
