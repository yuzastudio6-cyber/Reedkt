# Production Text Behind Subject Execution Policy

Text-behind-subject requires a strong foreground mask or mask sequence, safe text content, safe placement, and QA. Low-confidence masks must downgrade to foreground-safe text, a side panel, or a lower third.

M15C produces text layer metadata and a `render_manifest` with `manifestKind=depth_composition_manifest`. This is a Remotion/Hyperframe handoff description only.

No final render, full Remotion render, Revideo path, ASS/HTML/script injection, or source overwrite is allowed.

## Activation Phase 33E

Phase 33E created one private single-frame text-behind-subject preview from the
approved Phase 33D frame, mask, and RGBA cutout. The text was fixed to
`REEDITPRO`, and the output was a private PNG with depth composition metadata
and QA.

This does not approve arbitrary text, full-video text-behind-subject, public
delivery, production, external beta, broad real media, providers, GPU, model
downloads, or Revideo.
