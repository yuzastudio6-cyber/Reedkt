# Phase 36M Audio/Timing Allowed Internal Scope

Allowed after a passing Phase 36M decision:

- restricted internal QA/planning use of committed DeepFilterNet bounded speech-cleanup evidence
- restricted internal QA/planning use of committed Signalsmith bounded timing/stretch evidence
- review of committed safe metadata reports and private JSON metadata manifests
- planning follow-up audio/timing phases with explicit approval gates

Not allowed:

- product-wide beta
- external beta
- paid production or production
- broad media, arbitrary media, unapproved real media, or public output
- DeepFilterNet or Signalsmith runtime reruns through Phase 36M
- Demucs runtime, model download, or source separation
- OCR/VLM runtime retries, providers, Docker, Cloud Run, Cloud Build, GPU jobs, IAM mutation, or Track A
