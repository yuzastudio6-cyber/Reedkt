# Phase 44N Metadata Route Dry-Run Artifact Scope

The artifact scope allows only approved private media-data metadata and approved plan-snapshot metadata as inputs, and private reporting metadata as output.

Media, audio, model payloads, provider output, public artifacts, signed URLs as source of truth, arbitrary local paths, arbitrary GCS prefixes, broad media, and committed private payloads are blocked.

Phase 44N performs no payload upload.
