# Open-Source Editing Tool Registry

Status: runtime planning registry. This document tracks worker/runtime candidates and their production approval state. It is separate from the top-level planning registry and does not install, execute, or approve any new production tool by itself.

No provider calls, Stripe/payment flows, production deploys, customer media processing, broad queue drains, or service account JSON keys are enabled by this registry.

## Runtime Approval Rules

- Staging smoke approval is not production approval. Remotion and FFmpeg have only passed narrow staging smoke paths.
- Runtime tools must run behind backend/worker boundaries with approved snapshots, credit gates, storage provenance, bounded timeouts, and cleanup.
- Canonical records must store bucket/object paths and metadata, not signed URLs, raw media bytes, secrets, or provider payloads.
- Production approval requires dependency/license review, security review, resource caps, failure handling, monitoring, and a separate production rollout decision.
