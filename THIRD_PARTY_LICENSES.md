# Third Party Licenses

## Demucs

Demucs source code is distributed by Meta/Facebook Research under the MIT
license in the official `facebookresearch/demucs` repository.

Demucs model weights are treated as separate artifacts. ReeditPro/Dukira does
not infer commercial model approval from the code license. Runtime use requires
a company-controlled model artifact with `approval.json`, provenance, license
evidence, and SHA-256 verification.

Runtime model downloads are disabled.

## DeepFilterNet

DeepFilterNet remains the speech cleanup engine for Clean Voice, Enhance Speech,
Remove Background Noise, Speech Denoise, and Voice Cleanup. Its tool/model
approval is tracked separately in the Phase 36B-36F evidence chain.
