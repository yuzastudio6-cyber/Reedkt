# Phase 37A OCR Model Approval Runbook

Phase 37A records PaddleOCR and PaddlePaddle evidence for future OCR safe-zone work. It approves planning only for generated UI/text fixture OCR, caption safe-zone metadata, text/UI region detection, and private artifact output.

No OCR model download, PaddlePaddle runtime execution, OCR inference, real media processing, Docker build, GCP mutation, provider call, Revideo path, public URL, production approval, external beta, or broad real media testing is allowed in Phase 37A.

Review `activation:ocr-model-approval:plan`, `activation:ocr-model-approval:report`, and `activation:ocr-model-weight:summary`. Phase 37B may begin only as exact official PP-OCRv5 asset selection and private staging download planning.
