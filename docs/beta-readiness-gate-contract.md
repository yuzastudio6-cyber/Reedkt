# Beta Readiness Gate Contract

This contract defines the gates that must pass before production-level beta testing. Prompt 18 records gate expectations only; it does not grant legal, security, runtime, deployment, or production approval.

| Gate | Purpose | Pass condition | Fail condition | Evidence | Owner | Environment | Current status | Fix milestone | User-facing failure style | Future audit event |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SourceOfTruthGate | Confirm docs and trackers align. | Prompt 0-18 status files agree. | Missing or contradictory source of truth. | `PRODUCTION_FOUNDATION_STATUS.md`, source map, prompt tracker. | Foundation | Local static | Partial | Prompt 18 | "Readiness evidence is incomplete." | `beta.source_of_truth.checked` |
| ArchitectureBoundaryGate | Preserve frontend/backend/worker/provider boundaries. | Boundary docs and diagnostics pass. | Any runtime path crosses a blocked boundary. | Architecture freeze and route diagnostics. | Backend | Local static | Partial | Prompt 18A if failed | "Runtime boundary is not ready." | `beta.architecture_boundary.checked` |
| CanonicalSchemaGate | Use canonical table targets. | Schema contracts identify targets and conflicts. | Legacy tables become primary production targets. | Canonical schema docs/static audit. | Data | Local static | Partial | Prompt 19 | "Schema target is not validated." | `beta.schema.checked` |
| MigrationValidationGate | Validate migration chain. | Local/staging migrations pass in approved env. | Migration chain untested or conflicting. | Future local/staging logs. | Data | Local/Staging | Blocked | Prompt 19 | "Database migration validation is pending." | `beta.migration.checked` |
| RLSValidationGate | Verify access policies. | Local/staging RLS smoke tests pass. | SQL remains draft-only or fails. | RLS logs and test results. | Data/Security | Local/Staging | Blocked | Prompt 19 | "Access policy validation is pending." | `beta.rls.checked` |
| AuthWorkspaceGate | Validate auth and project access. | Member/non-member cases pass. | Any cross-workspace access. | Auth route tests/RLS. | Backend | Local/Staging | Partial | Prompt 19 | "Workspace access is not validated." | `beta.auth_workspace.checked` |
| StorageUploadGate | Validate private upload path. | Private bucket and object records pass. | Public source media or unsafe paths. | Storage policy smoke. | Backend/Data | Staging | Blocked | Prompt 20 | "Storage is not beta-ready." | `beta.storage.checked` |
| SignedUrlGate | Keep signed URLs temporary. | No signed URL source-of-truth storage. | Signed URL persisted or exposed. | Storage diagnostics and staging audit. | Backend/Security | Staging | Blocked | Prompt 20 | "Signed URL boundary is not ready." | `beta.signed_url.checked` |
| ApprovedSnapshotGate | Require immutable approved plans. | Snapshot references pass integrity checks. | Workers can use raw chat or mutable plan. | Snapshot route/RLS evidence. | Backend | Staging | Partial | Prompt 21 | "Approved plan snapshot is required." | `beta.snapshot.checked` |
| CreditLedgerGate | Enforce credit approval/reservation. | Transactional credit gate passes. | Spend/reserve/refund mutation is missing or unsafe. | Credit RLS/transaction logs. | Backend/Billing | Staging | Blocked | Prompt 22 | "Credit gate is not ready." | `beta.credit.checked` |
| BackendApiGate | Confirm route surfaces fail closed. | Route registry and diagnostics pass. | Execution route is production-ready without runtime. | Backend API diagnostics. | Backend | Local static/CI | Partial | Prompt 18A if failed | "Backend route is not ready." | `beta.backend_api.checked` |
| JobWorkerGate | Validate worker claim contract. | Transactional claim/lease tests pass. | Real execution can start unsafely. | Job/worker RLS and contract tests. | Backend/Worker | Staging | Blocked | Prompt 23 | "Worker runtime is not ready." | `beta.job_worker.checked` |
| MediaReadinessGate | Validate media readiness path. | Metadata/probe/timing readiness passes with safe fixtures. | Real media processing starts early. | Media readiness smoke. | Worker/Media | Staging | Blocked | Prompt 24 | "Media readiness is incomplete." | `beta.media.checked` |
| RenderPreviewExportGate | Validate render/export blockers. | Preview/export requests stay gated until runtime approved. | Render/export starts without gates. | Render route/RLS evidence. | Render | Staging | Blocked | Prompt 25 | "Render/export is not ready." | `beta.render.checked` |
| QARevisionFallbackGate | Validate QA/revision boundaries. | QA blockers and revisions remain gated. | QA/revision/fallback executes unsafely. | QA route/RLS evidence. | QA | Staging | Blocked | Prompt 26 | "QA and revision gates are not ready." | `beta.qa.checked` |
| ToolCallGate | Validate tool intent boundary. | Tool intent remains approved-snapshot-bound. | Tool execution can start early. | Tool-call diagnostics/RLS. | Worker/Tools | Staging | Blocked | Prompt 27 | "Tool calls are not ready." | `beta.tool_call.checked` |
| ToolReadinessGate | Validate tool runtime disabled state. | All tools remain disabled until approved. | Any tool is runtime-enabled without review. | Tool readiness diagnostics. | Tools/Security | Local static/CI | Partial | Prompt 27 | "Tool runtime is disabled." | `beta.tool_readiness.checked` |
| WorkerExecutionContractGate | Validate execution envelope. | Envelope has approved snapshot, credit, media, tool gates. | Envelope allows execution before runtime. | Worker execution diagnostics. | Worker | Local/Staging | Partial | Prompt 23 | "Worker execution contract is incomplete." | `beta.worker_execution.checked` |
| ProviderGatewayGate | Validate provider blockers. | Provider catalog/envelope checks pass; calls blocked. | Provider call/secret read occurs. | Provider diagnostics. | Backend/Providers | Local/Staging | Partial | Prompt 28 | "Provider gateway is not ready." | `beta.provider.checked` |
| ComplianceReviewGate | Require human compliance/security review. | Human-reviewed compliance records exist. | AI-generated docs treated as approval. | Compliance runbook and review evidence. | Legal/Security | Staging | Blocked | Prompt 29 | "Compliance review is required." | `beta.compliance.checked` |
| ObservabilityAuditGate | Validate audit/observability. | Persistent audit and alerting are reviewed. | No audit evidence or unsafe telemetry. | Observability diagnostics/staging logs. | Ops/Security | Staging | Blocked | Prompt 30 | "Observability is not ready." | `beta.observability.checked` |
| AbuseRateLimitGate | Enforce abuse/rate policy. | Persistent rate-limit/abuse controls pass. | No durable enforcement. | Policy tests and audit logs. | Ops/Security | Staging | Blocked | Prompt 30 | "Rate-limit and abuse controls are pending." | `beta.abuse_rate_limit.checked` |
| CostControlGate | Enforce cost controls. | Usage/cost controls pass with billing-safe limits. | Unbounded spend possible. | Cost-control logs and policy tests. | Ops/Billing | Staging | Blocked | Prompt 30 | "Cost controls are pending." | `beta.cost_control.checked` |
| StagingE2EGate | Run full staging smoke. | Approved staging smoke passes and cleanup succeeds. | E2E not run or leaves unsafe records. | Future staging smoke report. | Release | Staging | Blocked | Prompt 31 | "Staging E2E evidence is missing." | `beta.staging_e2e.checked` |
| HumanReviewGate | Require release owner signoff. | Human release/security/product approval exists. | Automated docs treated as signoff. | Signed release checklist. | Product/Security | Staging | Blocked | Prompt 31 | "Human release approval is required." | `beta.human_review.checked` |
| ProductionUnlockGate | Prevent accidental unlock. | Production unlock stays false until all gates pass. | Production/beta flag enabled early. | Diagnostics and release checklist. | Release | Production | Blocked | Prompt 31 | "Production beta remains blocked." | `beta.production_unlock.checked` |
