# Phase 40C Real-Video Pro Color/Image QA Policy

Mandatory QA gates:

- `source_integrity`
- `phase40b_evidence`
- `plan_snapshot_integrity`
- `sample_bounds`
- `openimageio_real_frame`
- `opencolorio_real_frame`
- `kornia_real_frame`
- `artifact_privacy`
- `blocked_features`

Phase 40D readiness is allowed only when every mandatory gate passes. Readiness
means only that a private pro color/image feature E2E readiness gate may be
planned. It is not approval for full-video processing, final delivery,
production, external beta, paid production, or broad real media.
